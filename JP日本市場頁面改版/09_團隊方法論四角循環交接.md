## 目標

把 `/jp/overview` 第 7 段「團隊組成」（cascading slider）跟第 6 段「方法論」合併：
拿掉方法論獨立 section，內容併入部門介紹，四張卡從底部橫排改成圖片四個角落，
中間加箭頭徽章，形成一個視覺上的循環（左上→右上→右下→左下→回到左上）。

這是 Terris 在對話中連續提了 3 次的需求，最後一次原文：
「需要把產品的頁面跟部門團隊頁面整合，打造產品的方法要把四個卡片直接寫上去部門，
然後幫我把圖片放更大、拉長之後，把四個卡片變成四角，加上箭頭，變成一個循環」

## 我實際做的改動（已用 API 讀回確認「有寫入」，但沒有確認「畫面正確」）

### 1. 內容改成四個部門（這部分有把握是對的，讀回文字內容確認過）

| 卡片 | Element ID（標題／內文） | 新內容 |
|---|---|---|
| 卡 1 | `ef66fb18...5142` / `...5144` | 客戶成功與照護專業 |
| 卡 2 | `ef66fb18...5149` / `...514b` | 產品與設計 |
| 卡 3 | `ef66fb18...5150` / `...5152` | 軟體工程 |
| 卡 4 | `ef66fb18...5157` / `...5159` | 資料科學 |

Section 標籤／標題／導言也一併換成 Codex 08 文件的「團隊與專業」定稿文字。

### 2. 背景圖放大

Class `.jp-method_img`：`height` 從 `34rem` 改成 `46rem`。

### 3. 四張卡從橫排改成四角（**這是最可能沒生效的部分**）

- `.jp-method_process.is-over-image`（原本是 `position:absolute; bottom:1.5rem` 置中橫排的容器）
  改成 `position:absolute; inset:0（top/left/right/bottom:0）; width:100%; height:100%; display:block`，
  用意是讓它變成一個鋪滿圖片的定位容器。
- 新建 4 個 combo class，掛在 `.jp-method_process-item.is-overlay` 之下：
  - `is-corner-tl`：`position:absolute; top:0; left:0; width:17rem`
  - `is-corner-tr`：`position:absolute; top:0; right:0; width:17rem`
  - `is-corner-br`：`position:absolute; bottom:0; right:0; width:17rem`
  - `is-corner-bl`：`position:absolute; bottom:0; left:0; width:17rem`
- 四張卡（element `ef66fb18...5146`／`...514d`／`...5154`／`...515b`）依序套上
  `is-corner-tl`／`is-corner-tr`／`is-corner-br`／`is-corner-bl`。

用 `query_styles` 讀回，這 4 個 combo 跟外層容器的屬性都確實存在（`position:absolute` 等），
但**沒有辦法確認瀏覽器實際渲染出來是不是四個角落**——有可能是某層還有沒抓到的 `overflow` 或
z-index 蓋住、也可能是 Designer 端跟已存的樣式之間有沒同步的落差。

### 4. 四個箭頭徽章

新建 class `.jp-method_flow-arrow`（圓形、品牌藍底、白字）+ 4 個方向 combo
（`is-flow-top`／`-right`／`-bottom`／`-left`，各自用 `top/right/bottom/left: -1.5rem` 讓徽章卡在邊界中點）。
過程中第一次用 `TextBlock` 元素類型建立，結果文字寫不進去、顯示 Webflow 預設的
「This is some text inside of a div block.」佔位字（`06_Webflow實作陷阱.md` 第 2 條的雷）。
已刪除重建成 `Paragraph` 類型，讀回確認文字是 `→ ↓ ← ↑` 沒錯，但**同樣沒有可信的畫面確認**。
