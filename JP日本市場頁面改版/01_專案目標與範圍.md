# 01 專案目標與範圍

## 專案定位

本專案維護 `/jp/overview` 與 `/jp/about-us` 兩個日本市場 Draft 頁面。

- `overview`：品牌、產品能力、JuboLink、團隊方法與信任資訊。
- `about-us`：企業情報、經營團隊、日本／MDX 合作脈絡、據點與詢問表單。
- 主要受眾：日本代理商、合作夥伴與需要查證公司資訊的 B2B 讀者。
- 網站本體在 Webflow；本 repo 是規範、決策與交接，不是網站原始碼。

## 目前階段

截至 2026-08-20，兩頁內容與主要版面大致完成，但仍在發布前 QA／重構階段。不得把「內容齊全」寫成「結構完成」或「可發布」。

## 不可違反的規則

1. 兩頁維持 `draft: true`，未取得明確指示不得 Publish。
2. 以 Client-First 結構為基準：`page-wrapper > main-wrapper > section_* > padding-global + padding-section-* > container-*`；既有 `all-sections-wrapper` 可保留。
3. 不修改共用 Component definition、utility class 或 variables。
4. 不直接 rename 既有 class；建立新 class、重新掛載、全站使用數歸零後再清理。
5. Slater 鎖定 selector 必須保留原名，詳見 `../custom-code/slater-selectors.md`。
6. 新 custom class 用 `folder_element`，變體用 `is-*`；避免新增 `jp3-*`、`jp-partner-*` legacy 命名。
7. 色彩、spacing、圓角優先使用既有 variables 與 utility。
8. 四個斷點皆需驗收：main、medium、small、tiny。
9. 新增文字先用繁體中文；日文只使用已校稿版本。
10. Repository 快照可能落後；執行前需讀回 Webflow 即時結構。

## 完成定義

- 每頁恰有一個 H1，heading 層級按 DOM 順序連續。
- 文字對比、圖片 alt、連結與表單符合發布標準。
- 四斷點無 overflow、截斷、重疊或不合理雙重留白。
- Overview 的 section spacing 與 container 已收斂到可維護系統，不再靠局部 margin 修補。
- 所有待刪 class 已完成全站使用與 Slater selector 確認。
- 兩頁互相導覽及 JuboLink／MDX 導線可點擊並讀回驗證。
- 未污染共用樣式，兩頁仍為 Draft。
