## 6. 回到頁首按鈕（2026-09-08）

`/jp/about-us` 頁尾原本沒有任何回到頁首的入口，而這頁很長（公司概要表 11 列＋領導團隊＋MDX＋表單），
且 JP 兩頁刻意不放 Navbar／Footer，捲到底之後沒有任何導覽可用。因此在最後新增一段只放一顆按鈕的 section。

### 設計結論

- 外觀沿用站上的 **glass button 語彙**：`glass-button` → `glass-element` ＋ 新 combo `is-to-top` →
  `glass-effect is-icon` ＋ 7 層 `glass-effect__* is-icon` 材質層 → 兩個 `gradient-icon`（`is-1` / `is-2`）。
  除了 `is-to-top`（尺寸／置中／旋轉）與 `jp-about_to-top-wrap`（水平置中）之外，**沒有新增任何視覺樣式**。
- 形狀是圓形而非膠囊：`glass-element` 基底已有 `border-radius: 50em`，combo 只給 `3.25rem` 正方尺寸並把
  基底的 `padding` 歸零，就自然變成 52px 圓形（≥44px，符合觸控目標）。
- 箭頭是站上 CTA 用的同一顆漸層箭頭 SVG（`#00B2C0` → `#3B58FF` 72%），**沒有另外畫圖**。

### 為什麼箭頭朝上是靠旋轉容器，不是換一張朝上的 SVG

Slater CSS（`slater.app/20018/60294.css`）用 `!important` 鎖住兩顆箭頭的 transform：

```css
.gradient-icon.is-1 { transform: translateX(0%) scale(1) !important; }
.glass-button:hover .gradient-icon.is-1 { transform: translateX(150%) scale(0.5) !important; }
.gradient-icon.is-2 { transform: translateX(-150%) scale(0.5) !important; }
.glass-button:hover .gradient-icon.is-2 { transform: translateX(0%) scale(1) !important; }
```

箭頭自己的 `transform` 完全不能動（改了會被 `!important` 蓋掉，或蓋掉之後就沒有滑入滑出動畫）。
所以改成**旋轉外層膠囊**：`.glass-element.is-to-top { transform: rotate(-90deg) }`。
站上的 CTA 是 `.glass-element.is-icon { transform: rotate(-45deg) }`（右上斜箭頭），同一個手法。
旋轉 -90° 之後，右向箭頭在畫面上朝正上方，而 Slater 的 `translateX` 也跟著變成「往上滑出、下一顆從下方滑入」，
剛好就是回到頁首該有的動態。

### `.gradient-icon.is-2.is-to-top` 為什麼必須存在

`.gradient-icon.is-2` 是 `position: absolute; left: 5px`，那個 5px 是為站上 `1.75rem` 小膠囊算好的
（(28 − 18) / 2 = 5）。放進 `3.25rem` 圓形之後會偏左約 12px，hover 時第二顆箭頭會歪掉。
因此加 combo `left: calc(50% - 0.5625rem)`（0.5625rem = 18px 的一半）把它拉回中央。
**不可以改 `.gradient-icon.is-2` 本身的 `left`** —— 那是全站共用值。

### 為什麼沒有直接插 Glass Button component

`04_素材與識別碼.md` 的原則是「按鈕直接用 Glass Button component，不要手刻」。這次是例外，原因是：

1. 該 component 只有 base 一個 variant、兩個 props（`CTA Text`／`CTA Links`），**一定會帶文字**，
   而這顆按鈕要的是「中間一顆漸層箭頭」的圖示型按鈕。
2. 它有 105 個實例，改 component definition 會影響全站（違反鐵律 5）。
3. 手刻的風險原本是「沒有動畫」，但實測 Slater CSS 是用 **class selector**（`.glass-button:hover .gradient-icon.is-1`）
   驅動箭頭，不需要 `data-w-id`，所以沿用同一組 class 就會有同一個動畫。
   文字逐字動畫是 Slater JS 讀 `data-button-animate-chars`，這顆按鈕沒有文字，用不到。

> 殘留風險：`04` 記載箭頭動畫是 IX2。實測 Slater CSS 帶 `!important`，理論上會蓋掉 IX2 寫的 inline style，
> 但**這點尚未在 staging 實測**。若 hover 沒有動畫，就把這顆按鈕換成 wrapper + Glass Button component（會帶文字）再議。

### 無障礙與捲動

- 圖示型連結沒有可讀文字，因此 `<a>` 上掛 `aria-label="ページトップへ戻る"`。兩顆 SVG 都是 `aria-hidden="true"`。
- 捲動用 Webflow 原生 anchor：`link = "#page-top"`（`linkType: url`，避開 `06` §1 的 `linkType: page` 靜默失敗），
  目標是最上層 hero section `534fcc9e-…-f26f` 新掛的 DOM id `page-top`。沒有寫任何 JS。
- **不是**捲動才浮現的 floating toggle。scroll-triggered 顯示／隱藏要靠 IX2，而 MCP 讀不到也寫不了 IX2
  （`06` §8）。若 Terris 要浮動版，需在 Designer 手動加 IX2 或請 Slater 加規則，這裡先做頁尾常駐版。
