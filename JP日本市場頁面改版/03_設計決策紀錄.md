# 03 設計決策紀錄

> 本檔只保留仍有效的決策。已被推翻的版本可從 `07`、`09`、`10` 與 git history 查閱。

## 1. 兩頁資訊分工

- `/jp/overview` 負責品牌、產品、方法、歷程與信任敘事。
- `/jp/about-us` 負責企業情報、領導團隊、日本／MDX 合作背景、據點與詢問。
- About Us 現在保留 Hero；早期「不做 Hero」決議已被 Terris 後續實作取代。

## 2. Overview 產品段落前移

JuboLink／解決方案目前在最後一段。為了讓日本合作夥伴在品牌介紹與可信數據之後立即理解產品，建議移到第 3 段。

建議順序：Hero → 關於 Jubo／數據 → JuboLink／解決方案 → 創辦人／Manifesto → 歷程 → 理念 → 團隊方法 → 資訊安全。

這是已確認的設計方向，但尚未執行；移動時必須整段移動 Webflow Slider 結構，不可拆散 children。

## 3. 部門與方法論

- 舊部門 cascading slider 已刪除。
- 現有「不同專業一起」四角方法論區保留。
- 不再重建舊 slider，也不再新增箭頭徽章，除非 Terris 另行指定。
- `cascading-slider*` class 仍可能被 internship 與 Slater 使用，不得因 Overview 已刪除實例而全站刪除。

## 4. Spacing 收斂

- About Us 維持廠商 Client-First：每個 section 使用 `padding-global padding-section-large` 與 `container-large`。
- Overview 逐區把 `jp3-section`／`jp3-container` 遷移到標準 section padding／container。
- 不直接 rename 或改寫 legacy class；先建立新 class／工具類組合並重新掛載。
- 創辦人與 Manifesto 的雙層 section padding 必須拆開處理，不使用負 margin 補救。

## 5. Class 清理原則

1. 仍在頁面使用的 `jp3-*`、`jp-partner-*` 是「待遷移」，不是「可刪」。
2. 空白 overlay／glow／gradient 元素屬於視覺結構，不因沒有文字就刪除。
3. Slider nav、arrow、`demo_hide` 先視為必要結構。
4. 只有跨站使用數為 0、且未被 Slater／IX2／Component 依賴的 class 才能刪除。
