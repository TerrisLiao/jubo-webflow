### 2. 經營團隊

四張卡，**桌面 2×2**，右欄（第 2、4 張）以 `transform: translateY(3rem)` 做**階梯錯落**
（用 transform 而非 margin，才不會影響 grid 的列高計算）。

**卡片結構**：`jp-about_leader-card`（`aspect-ratio: 2/3`、`overflow:hidden`）
> `jp-about_leader-photo`（滿版 `object-fit:cover`）+ `jp-about_leader-overlay`（貼底、固定 `height:40%`）
> `jp-about_leader-glass`（玻璃面板，`height:100%` 撐滿疊層以確保四張卡等高頂齊）
> `jp-about_leader-name` / `-title` / `-bio`

| 職稱 | 姓名 | 照片裁切 |
|---|---|---|
| 創辦人暨執行長 CEO | 康仕仲 | base `object-position: 50% 20%` |
| 副執行長暨營收長 CRO | 謝美芬 | combo `is-cro`：`50% 40%` |
| 技術長 CTO | 古凱元 | combo `is-cto`：`50% 37%` |
| 數位長 CDO | 李泓其 | base `50% 20%` |

- 卡片比例刻意設為 `2/3`，**與照片原始比例一致**，`object-fit:cover` 的裁切量因此為零。
- 兩個 `is-*` combo 的存在理由：四人在原始照片裡的髮際線高度不同（14%／15%／20%／21%），
  用同一個裁切錨點會導致頭部高度不齊。詳見 `03_設計決策紀錄.md`。
- 姓名**不含**英文名與學位；職稱**保留**英文縮寫但**不加括弧**（例：`創辦人暨執行長 CEO`）。
- ⚠️ COO 陳依伶尚未列入（照片未更新）。

### 3. 服務據點

沿用 `jp-about_profile-table` 的 label/value 版式，三列：台北研發總部／台南辦公室／北美分公司。
每列值容器內含：**照片**（`jp-about_office-photo`，`width:50%`、`aspect-ratio:16/9`）、
地址、電話／Email、Google 地圖連結（`jp-about_office-link`）。

照片來源是 CMS collection「全球服務據點」的 Cover Image，**已另存為獨立 asset 使用**
（原因見 `04_素材與識別碼.md`）。

### 4. 日本市場詢問表單

- 外層 `jp-about_form-wrap`（`max-width: 37.5rem`、置中）—— 讓表單對齊置中的標題區。
- 欄位：公司名稱／姓名／電子郵件／電話（選填）／詢問內容。
- 每個欄位是「`jp-about_field-label` 一行式標籤 + 輸入框」的上下組合。
  詢問內容那格額外套 `jp-about_field-full`（`width:100%`）讓底線撐滿整列。
- 表單標記 `data-ga-form-type="japan-market"`，欄位 domId 為 `jp-company`／`jp-name`／`jp-email`／`jp-phone`／`jp-message`。

> ⚠️ Webflow MCP **無法設定表單欄位的 placeholder**，所以這裡用顯性標籤而不是 placeholder。詳見 `06_Webflow實作陷阱.md`。

### Hero 的兩個角落元素

- **左上角**：既有的白色 Jubo 字標（`jp-hero-jubo-logo.is-top-left`，inline SVG，`currentColor`）。
- **右上角**：本次新增的「企業情報」按鈕。
  外層 `jp-overview_hero-nav` 只負責定位（**完全鏡像**左上角字標的那組數值，含三個斷點偏移），
  按鈕本體是站上既有的 **Glass Button component**（`71b87018-1f96-f193-c4a1-6b778017a800`，全站 94 個實例），
  props：`CTA Text` = 企業情報、`CTA Links` = `/jp/about-us`。

  > ⚠️ **一定要用這個 component，不要手刻。** 它的箭頭與文字動畫不在 CSS 裡：
  > 文字逐字位移由 Slater 透過 `data-button-animate` / `data-button-animate-chars` 驅動；
  > 箭頭是**兩份圖示疊放**（`gradient-icon is-1` / `is-2`），hover 時一份滑出、一份滑入，
  > 由 Webflow Interactions（IX2）以 `data-w-id` 綁定。手刻的靜態按鈕看起來像，但完全沒有動畫。

> ⚠️ 這裡刻意**不做獨立的 header bar** —— 站上既有語彙是「logo 直接疊在 hero 圖上」，
> 多做一條 bar 會與之衝突，也會把內容往下推。詳見 `03_設計決策紀錄.md`。
