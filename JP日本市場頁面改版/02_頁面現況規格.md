## 驗證限制

2026-08-28 合併作業：結構與 class 掛載已用 `element_id` 精確查詢讀回驗證；`element_snapshot_tool` 回 `status: false`（無可用 Designer session），因此**四斷點視覺與 computed style 未經驗證**，仍待人工 QA。

2026-09-08 回到頁首按鈕：結構、class 掛載、`link`、`aria-label`、兩個 Embed 的 SVG 內容都已用 `element_id` 精確查詢讀回驗證；新增的兩個 style 已用 `query_styles` 四斷點讀回。`element_snapshot_tool` 同樣回 `status: false`（Designer session 未連線），**四斷點視覺、hover 動畫與捲動行為未經驗證**，需 Terris 在 Designer／staging 實測。

Webflow 連接器可讀元素樹與 class 套用，但本輪無法可靠取得所有 class 的完整跨站使用次數與每個斷點全部 computed properties。任何 class 刪除仍須在 Designer Style Manager 與 Slater selector 清單做最後確認。
