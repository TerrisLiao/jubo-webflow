## 🔴 P0：還在線上的錯誤（成本低，應該先修）

### 1. 3 篇新聞 JSON-LD 解析失敗，整份 schema 無效

`/news/ai-transformation-culture`、`/news/amy-lense-intro-2026`、**`/news/system-cybersecurity`（新的一篇）**。

- 原因與 10/13 相同：新聞 template 的 `articleBody` 綁 `schema-plain-text`，欄位內容有換行，Webflow 輸出時不跳脫，JSON 斷掉。
- 10/13 的建議「拿掉 `articleBody` 再貼一次」**沒有做**：Webflow 讀回的新聞 template（10-20 09:08 更新）仍有 `"articleBody": "{{wf schema-plain-text}}"`。只要之後新文章的這個欄位有換行，就會再壞一篇。
- 另外 49 篇的 `articleBody` 是空字串，輸出空欄位也沒意義。
- **修法**：照 `custom-code/schema-templates/` 的流程，在 Designer 把 `articleBody` 那一行刪掉後重新貼上（不要用 API 寫 CMS template schema）。

### 2. `/products/residential-care` 的 schema 回退了

10/13 schema 檢查記錄已把這頁 7 個不帶 www 的網址改好，但 Webflow 讀回的現況是：

- `@id`、`url`、`offers.url`、`provider.url` 仍是 `https://jubo-health.com/...`（不帶 www）；
- `inLanguage` 是 `zh-TW`（全站 120 頁是 `zh-Hant-TW`，只有這頁、`/resources/education`、`/login` 是 `zh-TW`）；
- `provider` 沒有接 `#organization`。

頁面 `lastUpdated` 是 **10-13 05:30**，晚於 schema 修正的時間，研判是同一天加入產品頁 FAQ 10 題時，用舊版 schema 整份覆蓋。**已發布上線。**
同樣不帶 www 的還有 `/jp/overview`、`/jp/about-us`、`/login`。

### 3. 日期訊號是錯的：所有文章看起來都是 10/19 更新、案例都是 10/19 發布

| Collection | 欄位 | 線上值 | 問題 |
|---|---|---|---|
| 新聞 | `dateModified` | 52 篇幾乎都是 **2026-10-19** | 綁的是系統的 `updated-on`，一次批次編輯就讓 2019 年的新聞也宣稱「10/19 剛更新」 |
| 客戶案例 | `datePublished` | **24/24 篇都是 2026-10-19** | 綁的是系統發布時間，每次重新發布就重設；有一篇 `datePublished` 甚至晚於 `dateModified` |

AI 與搜尋引擎會看新鮮度（Playbook：95% 的 ChatGPT 引用來自 10 個月內更新的頁面），但**假的新鮮度會被識別並降權**，也讓真正有更新的文章沒有區別。

**修法**：客戶案例新增或改用一個人工維護的「發布日期」欄位；兩個 collection 新增「內容更新日」欄位，只有內容真的改了才改它，`dateModified` 綁這個欄位。

## 驗證方法與限制

- **線上抓取**：2026-10-21 從 `sitemap.xml` 取 135 個網址，逐頁抓回 HTML（不轉址，135/135 回 200），用 BeautifulSoup 解析 title、description、canonical、robots、lang、hreflang、heading、`<main>`、OG、圖片、JSON-LD（解析錯誤、假評分、相對與非 www 網址、空字串、未定義 `@id`、FAQ 是否可見）。站內連結中不在 sitemap 的 11 個逐一追轉址檢查。
- **Webflow 讀回**：`list_pages`（61 頁）、`get_site`（發布時間）、`query_pages_schema_markup`（`/products/residential-care` 與新聞 template）。
- **效能**：Playwright + Chromium，Pixel 7 模擬、CPU 4 倍降速、延遲 150ms、下載約 1.6Mbps，量 LCP／CLS／long task 加總（近似 TBT）。量測機器不在台灣，**是實驗室近似值，不是 Google 的實際使用者資料（CrUX）**；PageSpeed Insights API 當日配額已滿。
- **沒有驗證的**：Webflow AEO／Analyze（403）、Search Console、GTM 後台、LinkedIn／Crunchbase／Ankecare 現況。
- 抓取與分析程式放在 session scratchpad，未進 git（可重建的大型輸出不提交）。
