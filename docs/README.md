## 維護

新任務更新 README、current-state、tasks、decisions、changelog、deployment；現況驗證日期與文件更新日分開。新文件不用全站流水號；跨文件引用完整檔名或可點擊連結，不再用「規範 18」等模糊指稱。

[來源匯入清單](workflows/import-manifest.json) 包含原 blob SHA、重疊版本與外部素材位置。原文保存不代表其中每個提案已被採用。
