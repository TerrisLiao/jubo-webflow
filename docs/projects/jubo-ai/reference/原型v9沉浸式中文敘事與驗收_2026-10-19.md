5. 故事線：認識 Jubo AI → 它不是單一產品，而是 Jubo 所有照護資訊系統背後的技術 → 用這套技術做出越來越多好用的小工具（例如 Amy、iBee）→ 我們有哪些資料、這些資料能做什麼、已經做到什麼 → 資料高度安全（引用資安頁的資安說法，避免被誤解為拿別人的資料做產品）→ 這個概念很有前景。
6. 整頁更多漸層與 AI agent 氛圍；N.Copilot 以置中的粗大字「認識 N.Copilot」登場，接著彈出對話框與幾個可點的按鈕；Amy、iBee 其餘維持。

## 4. 實作邊界

- 一個 Three.js r155 canvas／ShaderMaterial／draw call：全螢幕模糊漸層＋長虹玻璃稜線取樣、中央柔光、游標光團、漣漪、顆粒；依場景調整稜線強度、色彩飽和、色相與柔光。沒有圓形或球體。DPR 上限桌機 1.5、手機 1.25。
- 中文字體使用 Noto Sans TC（Google Fonts，隔離原型）；英數沿用 Poppins。正式站字體策略仍待決定。
- GSAP 3.13＋ScrollTrigger 只載入於隔離原型；正式原生實作依 GSAP 規範 §13 先評估 IX3 或重用站上 GSAP。
- 按鈕全部為一般 button（預覽 iframe 的 sandbox 不允許 form submit）。
- N.Copilot 原稿 path 未改；CTA 沿用站上 Glass Button 結構，文字改為「預約諮詢」。未修改共用 Component、Variables、utility、Slater 或站台腳本。
