# 原型 v2：沉浸式、置中、捲動驅動（取代 v1 版型與文案）

檔案：`custom-code/poc/jubo-ai-agentic-v2.html`（v1 保留作比較：`jubo-ai-agentic.html`）
依據：Terris 2026-10-14「不要沿用同樣的段落與文字；要很酷、更互動、全部置中、大量動態與捲動動畫、彈出互動」；參考 Mobbin 上的 Intercom（Fin）、SpaceXAI／Grok、Squarespace、OpenAI、Zaro。
文字直接寫在 HTML 內；`[待確認]` 黃底項目同 v1 待確認清單。

## 全頁機制

- 全頁一個固定 Three.js canvas（2,600 粒子，手機 1,400；1 draw call；pixelRatio ≤2；分頁隱藏停 loop；reduced-motion 速度 ×0.05）。
- 粒子在章節間變形：球 → 三層環 → 7 節點星座 → 速度光帶 → 球；開場由散落聚成球；滑鼠靠近粒子會避開。
- GSAP 3.12.5 ScrollTrigger：桌機三段 pin＋scrub（資料湧入、三層、速度）；手機不 pin，改進場動畫。
- 標題逐字浮出、右側章節導覽、數字以「解碼」效果出現（不是 counter 往上跳）。

## 與既有規範的衝突（Terris 已裁決採用 v2 方向）

- 研究 §5-3／§5-4 與 GSAP 規範建議：不 pin、不用裝飾性 WebGL、不做假產品 UI。v2 依 Terris 指示改為大量動態與 pin（手機仍不 pin）。
- 「換你下指令」為示意流程，非實際產品畫面，畫面上已標示；上線前需 Terris 確認此標示足夠。
- Webflow 實作前需真機測效能（Terris），掉幀依序：降粒子 → 降 pixelRatio → 手機改 CSS 背景。
