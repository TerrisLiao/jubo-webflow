## 可重跑的命令

環境已安裝 Chromium、Python Playwright；Node Playwright 本輪放在 `/tmp/v3-tools/node_modules`。此環境的瀏覽器禁止 `file://`，因此在 repo 根目錄啟動本機 HTTP；不涉及 Webflow 或網站部署。

```bash
python -m http.server 8765 --bind 127.0.0.1
```

另一個終端機執行交接 §8 的原指令，補上此環境所需的可選參數：

```bash
NODE_PATH=/tmp/v3-tools/node_modules \
POC_CHROMIUM_PATH=/usr/bin/chromium \
POC_BASE_URL=http://127.0.0.1:8765/ \
POC_HTTP_PROXY="$HTTPS_PROXY" \
node tools/poc-scroll-shots.js custom-code/poc/jubo-ai-agentic-v3.html /tmp/v3 1440,991,375

python tools/check-jubo-ai-v3.py
python tools/check_docs.py
git diff --check
```

- `poc-scroll-shots.js` 保留原來 file 預覽的預設；新增系統 Chromium／HTTP 預覽／代理的可選參數、JSON 報告與失敗 exit code。
- `check-jubo-ai-v3.py` 實際操作瀏覽器，覆蓋四狀態、四情境、情境取消、工具展開、確認、七彈卡、mobile pin／邊界與 reduced-motion。報表及截圖預設輸出 `/tmp/v3`，可由 `POC_OUTPUT_DIR` 改變。
- 外部 CDN 經環境代理載入；瀏覽器 CA 使用環境提供的憑證，未關閉 TLS 驗證。其他環境若已具備相應依賴與信任，可不設這些覆寫。
