## 3. 實作邊界

- 一個 Three.js r155 canvas、一個 ShaderMaterial、一個 draw call：紙色底、隨章節加深的色調、長虹玻璃（每條稜線取樣鏡像放大的光場）、磨砂玻璃圓、漣漪與顆粒感。DPR 上限桌機 1.5、手機 1.25（畫面本身是柔焦光，降低成本）。
- GSAP 3.13＋ScrollTrigger 只載入於隔離原型。官網已有 GSAP 3.15／ScrollTrigger；正式原生實作依 GSAP 規範 §13 優先評估 IX3，必要時重用站上的 GSAP，不重複載入。
- 循環動畫只在可見且未暫停時運作；Pause／Resume 同時停止 WebGL、打字與卡片循環；分頁隱藏停止 render。
- 示意全部標明 Illustration／no real case data；What if 標明 Ideas we’re exploring, not current products。
- N.Copilot 原稿 path 未改；Jubo Glass Button 結構沿用；未修改共用 Component、Variables、utility、Slater 或站台腳本。

2026-10-19 完整重跑：**All v8 browser checks passed**（exit 0）。四寬度、循環、互動、pin 場景、對話、彈窗、暫停全部通過；reduced-motion 1440／375 不 pin、靜態且三個構想可點；DPR 3 時桌機 1.5、手機 1.25；1280×600 改自然流；封鎖 Three.js 時 CSS 玻璃圓與對話可用；匯出 fixture（45458 字元 src，來源 SHA-256 `4605aabc3779db7589f9492e13cab915765e757861fc928f6f0c7fd4d2398695`）1440／375 可用。

製作中修正兩個實際問題：

1. 玻璃圓尺寸原本只在 scroll 事件時量測，GSAP scrub 在停止捲動後仍持續縮放 → 改為每幀追蹤錨點。
2. Webflow 預覽 iframe 的 sandbox 沒有 allow-forms，form submit 會被瀏覽器阻擋 → 輸入列與對話送出改為一般按鈕。v6（現行 Draft）與 v7 的對話送出鈕有同樣潛在問題，示例 chips 不受影響。
