## 3. v10 調整

| 項目 | v9 | v10 |
|---|---|---|
| 底色 | 全螢幕藍紫漸層＋長虹玻璃 | 暖米白 `#F6F5F1`，全頁一致 |
| 強調色 | 藍 → 紫 → 青漸層字 | 只用 Jubo 青（深青 `#007C85` 文字、`#00A3AE` 點綴）；無漸層字 |
| 長虹玻璃思考光 | 鋪滿全頁 | 只在三個大型圓角媒體面板內：Hero、N.Copilot 對話背景、結尾 CTA；色彩改為 Jubo 青、天空藍、薄荷、沙色（N.Copilot 面板帶一點品牌 Aurora 黃綠） |
| 字重 | 900 超粗 | 700 粗體，字距收斂，接近參考站的穩重感 |
| 按鈕／小元素 | 漸層圓點、紫色連結 | 黑色送出鈕與構想按鈕、青色圓點、近黑連結 |
| N.Copilot | 巨大標題與對話 | 巨大標題先出現；對話框彈出時，青色光面板同時亮起 |

互動全部保留：媒體面板內游標牽引光團與稜線高光、點擊漣漪、捲動越快光流越快、資料列 hover、遮蔽鏡、iBee 重播、N.Copilot 三情境、構想對話框。Shader 改為只在可見媒體面板的圓角矩形內繪製（每幀追蹤位置，跟得上 GSAP pin 與縮放），面板外為紙色；仍是單一 canvas、單一 draw call。
