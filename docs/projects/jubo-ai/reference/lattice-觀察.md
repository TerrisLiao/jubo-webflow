## 看到了什麼

| 階段 | 實際畫面手法 | v3 的轉譯 |
|---|---|---|
| 0–20 格 | 中央先只有細長指令框，左側 agent 標誌、右側送出箭頭；留白很大 | Hero 用 N.Copilot 頭像、指令輸入、送出鍵；chip 飛入輸入欄後才送出 |
| 40–60 格 | 指令框向下展開成對話面板；頂端改為 agent 身分列；原提問向右側泡泡移動、短暫模糊 | 示範面板進場後，右側使用者泡泡滑入，再出現左側 N.Copilot 身分與工作列 |
| 80–100 格 | 問題先站定，左側回答標題帶標誌漸入；答案分段變清楚 | 先顯示 shimmer 思考狀態，再依序呈現可展開的工具列；最後回答逐字輸出 |
| 140–179 格 | 回答內容與附屬操作依序完整出現；底部追問輸入列最後才出現 | 產出卡由對話中展開高度、內容逐行淡入；確認在最後，按下變為人員確認狀態 |
| 全程 | 身分清楚、問題靠右、回答靠左；柔和背景與大量留白，對話本身是焦點 | 全頁沿用亮底玻璃卡，換成原稿 N.Copilot、Teal Air 與取樣 Aurora；固定高度對話區內自動捲動 |
