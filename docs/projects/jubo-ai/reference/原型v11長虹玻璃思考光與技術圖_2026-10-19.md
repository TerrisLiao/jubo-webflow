# v11：長虹玻璃思考光主視覺與技術圖動態

## 2. 與資安頁的差異（回答 1）

技術上沒有差異。兩頁都用 CSS、SVG 與 GSAP 製作，Webflow IX3 底層也是 GSAP。差別在設計與製作方法：

| 項目 | 資安頁 | v8–v10 Jubo AI 頁 |
|---|---|---|
| 分鏡 | 每段先定內容，再設計專屬動態 | 先做共用光場，再把內容套進去 |
| 圖像 | 真實 Lucide 線條圖示、漸層筆畫、小型產品 UI 與說明 | 抽象占位：虛線、圓點、純文字標籤 |
| 打磨 | 依 Terris 回饋修改數十輪（`security/current-state.md` 記到 §65） | 每版一次成形 |
| 玻璃 | 一條長虹玻璃疊在漂浮色塊或照片上，不是一整塊面板 | v10 把思考光放進三個圓角面板 |
| 實作缺陷 | — | v10 技術圖用 `preserveAspectRatio="none"` 的 SVG，線條隨容器比例被拉伸，虛線粗細不一 |

## 3. v11 調整

| 項目 | v10 | v11 |
|---|---|---|
| 主視覺 | 圓角媒體面板內的光場 | **五片直立長虹玻璃鰭片**浮在無邊界的柔光上。每片寬度、高度與上下位置都不同；側邊為清楚的玻璃稜線，上下端融入光中；每片鏡像放大後方的光，並帶細稜紋、掃光與游標高光。光場在媒體範圍邊緣前就淡出，沒有直線切邊。手機上鰭片隨寬度變窄，彼此保留紙色間隙 |
| 媒體範圍 | 圓角、邊框、陰影 | 無邊框、無圓角、無陰影；Hero 全出血寬度 |
| 技術圖 | 虛線 X、純文字系統名 | 依實際像素計算的細曲線，由四個系統畫向中央；每條線上有兩顆光點沿 `offset-path` 流動；系統改為 Lucide 圖示（建築、太陽、房屋、網路），圖示筆畫填入青→天藍→薄荷漸層，背後有兩團模糊光緩慢漂移（資安頁的做法）；中央為柔光加一條 CSS 長虹玻璃 |
| 能力清單 | 純文字 | 每項加入同風格漸層圖示（搜尋、文件、鈴、筆、折線圖），捲到時亮起並放大 |

互動、故事、文案與場景順序同 v10。仍是單一 Three.js canvas、單一 draw call，沒有圓形或球體。
