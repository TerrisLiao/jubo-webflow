## 1. 最新需求與採用範圍

本輪取代 v3 的全頁粒子與全部 AI 使用 N.Copilot 身分的敘事：

- Jubo AI 展示照護領域的技術、知識、資料與流程能力。
- 全頁英文；乾淨白底逐步加入漸層，背景的連結與聚焦象徵理解過程。
- 平滑 glowing orb 是光場聚焦時的形態；磨砂玻璃承載內容，長虹玻璃呈現折射。
- 原版五類資料與五種用途全部保留。知識與工作資料分別呈現，不將累積紀錄數寫成訓練樣本數。
- N.Copilot 為 project-based conversational application；Amy、iBee 為既有系統 add-ons。
- iBee 呈現跨平台工作流程，不寫成由照護資料庫訓練生成。
- 未來用途明示「A possibility／Ideas for future applications」，不承諾新產品或日期。
- 同一已授權隔離 Draft 更新來源，不 Publish，不修改共用 Component／utility／Variables／Slater。

2026-10-14 實際讀取 [正式原版 Jubo AI](https://www.jubo-health.com/ai/jubo-ai)，當下主張為「讓 AI 真正理解照護工作」，包含五類資料、五種能力與 N-Copilot 專案應用。以下全部保留：

- 能力卡與 Amy／iBee 是概念 motion illustrations，不宣稱為實際產品截圖；產品完稿截圖仍待提供。

## 6. 動態與互動

- 一個 Three.js r155 canvas、一個 ShaderMaterial plane、一個 draw call，零 Points／粒子。
- 光場慢速變化；Hero／Context 使用同一 shader 球體，其餘段落淡開成背景；球面含內部色帶、柔和高光與 rim。
- DPR 桌機 ≤2、手機 ≤1.5；頁籤隱藏停止排程；全頁 Pause／Resume。
- 五張能力卡、Amy／iBee 約 4.8–5 秒有限次播放；首次進入視窗播放、hover／Replay 重播。
- 資料選取更新用途文字與能力卡；選取狀態有 aria-pressed 與文字。
- N.Copilot 示例 → 來源 → 逐項結果 → 人員 review；AbortController 取消前次示例。
- 原生 dialog 補焦點循環、Escape、返回觸發按鈕。
- Reduced motion 全文可見、無 CSS 動畫、無持續 render、無 sticky；互動仍可用。
- Three.js 不可用時保留 CSS 漸層球體、資料選取與對話。
