## 段落與互動

| 段 | 實作 |
|---|---|
| 1 Hero | 兩欄（`0.85fr 1fr`）。右欄「思考列」白卡：三組各三行逐行打字（15–25 cps），每組結束停 2.5 秒換下一組；`aria-live="polite"`；reduced-motion 一次顯示 A 組全文、不循環。背景 Three.js 資料點陣：約 1,200 點，從隨機散落收斂成柔和的球／波面，點色 accent＋light-teal，**一個 canvas、draw calls ≤10、pixelRatio ≤2、無後製、分頁隱藏停 loop、reduced-motion 速度 ×0.05**；寬度 <768 或 WebGL 不可用改為 CSS radial-gradient 靜態背景 |
| 2 規模帶 | 三欄靜態數字＋註腳 |
| 3 資料地圖 | 三欄 chip；點 chip → 段 4 對應卡片加 `is-linked` 樣式並以 SVG 曲線（stroke-dashoffset 動畫 600ms）連到卡片縮圖列；鍵盤可操作（button），`aria-pressed`；<768 改為 chip 下展開文字「這筆資料用在：…」 |
| 4 AI 卡片 | 5 張卡；資料標籤 chip；截圖區灰底佔位文字「截圖待補」 |
| 5 Amy／iBee | 兩欄卡；各一條月份時間軸；Amy 卡內「五段報告」進入視窗時依序淡入（IntersectionObserver，一次） |
| 6 三層 | 三層堆疊卡，第三層強調 accent 邊框 |
| 7 資安 | 四點 icon 列（Lucide 只取 SVG path） |
| 8 FAQ | `<details>` 原生 accordion；附 FAQPage JSON-LD |
| 9 CTA | 置中 |

步驟標籤 `01 讀取` 等用等寬小字＋accent 小方點，放在段 1、3、4、5、6 標題上方。

## 驗收

- 四斷點（1440／991／767／375）截圖無水平捲動、無文字溢出。
- `prefers-reduced-motion: reduce` 下無打字循環、點陣近乎靜止。
- Chrome DevTools 4× CPU throttle 下 hero 不明顯掉幀。
- Lighthouse a11y ≥ 90；所有互動可用鍵盤操作。
