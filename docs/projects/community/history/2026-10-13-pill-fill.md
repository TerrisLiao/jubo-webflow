# 社群追蹤頁：標籤裁切與頻道漸層填色

日期：2026-10-13（第三輪），頁面 `/community`，Page ID `6acde90ba4c1734c0e94b297`。
續作 `codex/community-card-motion`、[PR #21](https://github.com/TerrisLiao/jubo-webflow/pull/21)。

使用者提供目前三張卡片畫面，要求上方 tag 出格但超出部分不顯示，留在白色卡片內；hover 時兩個 tag 填滿不同漸層，呼應各 channel 主題。

## 採用結果

- 大 tag 尺寸與左右錯位保留；卡片 overflow visible → hidden，超出卡片邊界及圓角的部分裁切，不把全部標籤隱藏。
- 每個 tag 新增一個原生 `community-hero_channel-tag-fill` 絕對定位底層，opacity 0、z-index −1；父 tag position relative、overflow hidden、isolation isolate，確保底層位於文字下方並維持 pill 圓角。
- 底層均 aria-hidden、pointer-events none，並設語意化 Navigator 名稱；原文字、文字色 community/ink、外框與連結不變。
- Hover 保留較慢輕浮與其他卡片細節，新增兩個填色動作：.75 秒淡入，第一個從 .08 秒、第二個從 .20 秒開始；離開 .65 秒淡回透明。
- 三個頻道 IX3 每個 timeline 由 7 → 9 actions；保留 mouseEnter／mouseLeave role pair 及 reduced-motion dont-animate。右側時間軸不在本輪修改範圍。

| 頻道／標籤 | 填色 |
|---|---|
| Facebook 活動報名 | 藍青：#86B4FF → #55CBD5 |
| Facebook 現場花絮 | 淺天空藍：#9DF8FF → #C6D9FF |
| YouTube 三三分享會 | 珊瑚紅橘：#FF8993 → #FFBB78 |
| YouTube 專家觀點 | 蜜桃 lime：#FFE2BF → #DDEB4A |
| LINE 照護新知 | 綠 mint：#65DE97 → #06C755 |
| LINE 文章推播 | teal cyan：#00B2C0 → #9DF8FF |

以既有頻道色系延伸明亮填色，讓深色文字維持清楚；六組漸層 endpoint 對 community/ink 的對比皆 ≥4.76。沒有建立新 Variable 或更改共用色票。

IX3 不提供 backgroundImage tween；本輪以固定 gradient 底層淡入淡出達成填滿效果，不新增頁面 JS 或 Embed。

- 三個 hover 定義遞迴比對與預期一致；六組 gradient、六個底層 style 與 aria-hidden 讀回。
