# 三三分享會行銷執行 SOP（使用者提供原文）

> 來源：使用者於 2026-11-05 在 Claude session 中提供，原文保存，未改寫。
> 用途：節目專區與單集頁的維護時程以此為準（見 [設計提案](../design-proposal.md) §6）。
> 本文件是行銷流程，不是網站規範；其中只有「官網專區」「每集 Landing page」「主系統 Banner 導流」三項直接對應網站工作。

【前置作業】
一、半年確認一次主題規劃與講師推薦。
二、三個月前確認講師通告。（講師基本資料／確認講綱／約後台測試／約簡報提供日期）
三、兩個月前製作當集封面圖。
四、與講師確認簡報開放下載，資料授權、素材圖片無關個資等問題。（可以準備一個簡易的合作備忘錄公版，行銷部三三分享會用，釐清責任，請講師回簽畫押就好）

【事前宣傳】
一、官網專區：介紹三三分享會這個節目。三三分享會的主題規劃，過去重點主題、講綱、講師介紹、適合觀看的對象；歷次講師合作陣容；播放清單連結（導yt播放清單）
二、官網新聞/活動講座：每集Landing page，參考範例：三三分享會ep19，介紹當集內容、講師資歷、直播連結等影片資訊，以及索取課程簡報(填寫表單留下資本資料，獲得下載連結)。
三、主系統Banner：一個月前曝光，素材－參考每集Landing page＆講師初版簡報＆封面圖+CTA：直播提醒（導YT按小鈴鐺/導Line當天可收提醒訊息）or查看主題介紹（導每集Landing page）。
四、FB：兩週前預告一篇。LINE：當週預告一篇。

【直播當天】
一、Line：中午11:55 開播倒數五分鐘提醒。（CTA：觀看直播）
二、Banner：本日三三分享直播提醒，敬請準時收看。（CTA：觀看直播）
三、FB：前晚提醒一篇。（素材－封面圖＋CTA：導YT按小鈴鐺）

【回顧宣傳】
一、YT影片上架，後臺處理需要2~3天才能進行編輯。資訊欄新增影片段落摘要；影片結尾字卡關聯影片與播放清單/頻道訂閱。
（!!資訊欄位段落摘要涉及影片秒數，需要等影片剪輯final版確認後再進行摘要，會比較準確!!）
二、FB：兩週後回顧貼文一篇。（導yt影片）
三、LINE：一週後，提醒YT回顧影片上架一篇。（導yt影片）

【影片本身】三三分享會節目化
一、是否準備片頭、片尾動畫，在直播結束後YT上架完畢後可將動畫編輯加入影片本身。
二、開場制式介紹可預錄，開場12:00直接播。
三、片尾結尾漂浮字卡關聯影片與播放清單/頻道訂閱畫面設定。
四、腳本、畫面固定，避免影響視覺。（從畫面比例，講師位置，結尾畫面，與資訊卡位置設定是否衝突等等）
