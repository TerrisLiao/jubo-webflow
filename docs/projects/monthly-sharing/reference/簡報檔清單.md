# 三三分享會過去集數簡報檔清單（搬到 OneDrive 用）

2026-11-10 以 Microsoft 365 唯讀連線盤點 SharePoint：b-team-MSteam → `MS team/7.行銷活動/公司活動/【三三分享會】/{年} 三三分享會/{MMDD－主題}/`。每集的簡報檔都直接放在該集資料夾裡，沒有放在子資料夾。

連線只有讀取權限，複製檔案與建立分享連結要由人在 OneDrive 操作。

## 上傳方式（2026-11-10 改）

不用 OneDrive。把清單上的 PDF 傳給 Claude（或自己在 Webflow Designer → Assets 上傳），Claude 上傳到 Webflow Assets 後把公開網址填進 CMS「簡報下載連結」並打開「開放簡報」。單檔上限 30MB；Claude 上傳前會先壓縮圖片（150 dpi、JPEG 品質 70，文字保留可搜尋）。

已上傳（2026-11-10 測試）：EP18、EP19（講師版）、EP20、EP21，見下表「Webflow 網址」欄。

**不要複製**：各集資料夾裡的講師身分證、存摺影本、領款收據（`領款收據_…`、`…身分證…`、`…存摺…`、`…台新銀行.pdf`、`…元大銀行存摺.pdf`）。這些是個資，絕對不能公開。
