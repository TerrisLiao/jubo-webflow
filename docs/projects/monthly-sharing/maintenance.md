# 三三分享會專區：每月維護手冊

給行銷維護 `/resources/jubo-33-live-stream`（節目專區）與單集頁（簡報索取）用。所有內容都在 Webflow **CMS → 三三分享會集數**（另有「三三分享會講師」）維護，改完要 **Publish** 才會上線。

## 頁面上哪些內容會自動跟著 CMS 變

| 位置 | 顯示哪一筆 | 規則 |
|---|---|---|
| 最新消息卡（左：日期、分類、主題、LINE 按鈕；右：背景圖、講師、這集你會聽到） | 「狀態＝預告」裡直播時間最早的 **1 筆** | Collection List：狀態＝預告，直播時間由早到晚，取 1 筆 |
| 底部釘選條（下一集、日期、主題、開啟提醒） | 同上 | 同上 |
| 過去直播（四個分類卡底下的清單） | 「狀態＝已播出」且「封面圖」有值，依「分類」分到四欄 | 直播時間由新到舊 |
| 單集頁（`/monthly-sharing/ep22`，之後改 `/jubo-33-live-stream/ep22`）的課後問卷＋LINE 提醒區塊 | 該集 | 「開放簡報」打開才顯示（Designer 設定，見下方「一次性設定」）；送出後顯示「下載本集簡報」按鈕，連到該集「簡報下載連結」 |

**不會自動變、要手動改的**：最新消息區塊標題「11月份最新直播」的月份（頁面文字，在 Designer 直接改）。

## 一、新增下一集（約直播前一個月）

1. 講師是新的：先到 **CMS → 三三分享會講師** 新增（名字、單位、照片正方形≥400px）。
2. **CMS → 三三分享會集數 → New item**，填：

| 欄位 | 填法 | 範例 |
|---|---|---|
| Name | 主題 | 長照職場性騷擾與照護界線 |
| Slug | `ep`＋集數 | `ep22` |
| 集數 | 數字 | 22 |
| 直播時間 | 台北時間當天 12:00 | 2026/11/18 12:00 |
| 日期大字 | `月.日` | 11.18 |
| 狀態 | **預告** | 預告 |
| 分類 | 四選一 | 機構經營管理 |
| 講師 | 選講師 | 吳孟姿 |
| 封面圖 | Canva 宣傳圖（16:9） | — |
| 卡片背景圖 | Canva 宣傳頁的**無字版**（刪字、logo、講師照後匯出 1600×900） | — |
| 講綱 | 三點「這集你會聽到」，用項目符號 | — |
| 直播／回放連結 | YouTube 直播網址（直播與回放同一個） | — |
| 開放簡報 | 先關 | 關 |
| 簡報下載連結 | 講師同意後再填（見「四、開放簡報」） | — |
| 通關密語 | 已停用，不用填 | — |

3. Save → **Publish**。
4. 改最新消息標題的月份（例：「12月份最新直播」）。

只要同時只有 **一筆**「預告」，最新消息卡與釘選條就會顯示它。

## 二、直播結束後：把這集移到「過去直播」

1. 打開該集，**狀態改「已播出」**（封面圖要有值）。
2. Save → Publish。這集會自動出現在「過去直播」對應分類，最新消息卡會換成下一筆「預告」。
3. 若下一集還沒建立，最新消息卡會顯示空狀態文字「下一集主題即將公布…」；建議直播結束前就先建好下一集。

## 三、換最新一集（提前公布、或日期調整）

- 最新消息卡永遠抓「預告」裡**直播時間最早**的那一筆。
- 要換顯示哪一集：改各集的「直播時間」或「狀態」。
- 同時有兩筆「預告」時，只會顯示日期較早的那一筆。

## 四、開放簡報（講師同意後）

現行流程（2026-11-10 更新）：**看完直播 → 到單集頁填課後問卷 → 送出後直接出現「下載本集簡報」按鈕**。不再用通關密語，也不用到 LINE 領簡報；LINE 卡只負責「加好友收最新資訊與直播提醒」。課後問卷用單集頁上的 Webflow 表單，不再每月開 MS Forms。

1. 簡報轉 PDF（單檔 **30MB 以內**；太大先用 Acrobat「縮小檔案」或 ilovepdf 壓縮）。
2. 上傳到 Webflow：Designer 左側 **Assets** → 上傳 PDF（或把 PDF 傳給 Claude，會先壓縮再上傳）。點檔案 → 複製網址（`https://cdn.prod.website-files.com/…pdf`）。不必用 OneDrive，也不用逐檔設定分享。
3. CMS 該集：填「**簡報下載連結**」、打開「**開放簡報**」→ Save → Publish。
4. 直播結尾，聊天室貼**該集單集頁網址**（例：`https://www.jubo-health.com/jubo-33-live-stream/ep22`）請大家填問卷，取代以前的 MS Forms 連結。

注意：下載連結寫在單集頁的 HTML 裡（送出前隱藏），懂得看原始碼的人不填問卷也拿得到。簡報本來就是公開分享連結，可接受；若某集簡報不能外流，就不要開放。

以前設定過的 LINE「關鍵字自動回覆」（通關密語）可以關掉。

## 五、查看問卷名單

- Webflow：**Site settings → Forms**，表單名稱「**三三分享會簡報索取**」（每一集共用同一份表單）。
- 欄位（與原本 MS Forms 滿意度問卷相同順序）：索取集數（例「EP22 長照職場性騷擾與照護界線」）、Q1 機構類型、Q2 是否為智齡科技客戶、機構（公司）名稱、Q4 所在區域、姓名、職稱、Email、電話、Q9 內容實用程度（1–5 顆星）、建議或提問、得知管道（每個選項一欄）、期待主題或想說的話；另加「想了解智齡系統」與「個資同意」。單選題欄名前面的 Q 編號是技術需要（讓同一題選項互斥），不要改。
- 「索取集數」與單選題分組靠 Template 頁尾的 script（`<script id="sansan-deck-form">`，正本 `custom-code/monthly-sharing/sansan-deck-form.js`），不要刪。
- 可匯出 CSV。同一人每集都會再填一次，用 Email 篩可看出**固定參加的人**；業務名單篩「是否為智齡科技客戶＝否」，優先看「想了解智齡系統」有勾的人。
- 表單通知信收件人：在 Site settings → Forms 設定。

## 一次性設定（上線前，在 Designer）

1. 單集頁 Template 的課程簡報區塊（`section_sansan-deck`）已用 visibility 綁「開放簡報」（2026-11-10 以 API 完成），不需再設 Conditional visibility。
2. 隱藏欄位「索取集數」已由頁尾 script 填入，不需在 Designer 修 Embed。Embed 裡的 `{{wf …}}` 文字會被 script 覆蓋，可保留。
3. Collection URL 改 `jubo-33-live-stream`（單集頁網址變 `/jubo-33-live-stream/ep22`）。
4. 單集頁其他區塊尚未設計前，Template 先維持 Draft；要上線簡報索取時再取消 Draft。
5. LINE QR code 目前是用 `lin.ee/Clf7lXr` 自己產生的；若行銷有官方 QR 圖，換掉 `sansan-line-qr.png`。
6. 單集頁在哪裡：Designer 左側 **Pages → CMS Collection pages →「三三分享會集數 Template」**，右上可切換要預覽的集數。
