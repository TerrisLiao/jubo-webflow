# 三三分享會專區：每月維護手冊

給行銷維護 `/resources/jubo-33-live-stream`（節目專區）與單集頁（簡報索取）用。所有內容都在 Webflow **CMS → 三三分享會集數**（另有「三三分享會講師」）維護，改完要 **Publish** 才會上線。

## 頁面上哪些內容會自動跟著 CMS 變

| 位置 | 顯示哪一筆 | 規則 |
|---|---|---|
| 最新消息卡（左：日期、分類、主題、LINE 按鈕；右：背景圖、講師、這集你會聽到） | 「狀態＝預告」裡直播時間最早的 **1 筆** | Collection List：狀態＝預告，直播時間由早到晚，取 1 筆 |
| 底部釘選條（下一集、日期、主題、開啟提醒） | 同上 | 同上 |
| 過去直播（四個分類卡底下的清單） | 「狀態＝已播出」且「封面圖」有值，依「分類」分到四欄 | 直播時間由新到舊 |
| 單集頁（`/monthly-sharing/ep22`，之後改 `/jubo-33-live-stream/ep22`）的課程簡報區塊 | 該集 | 「開放簡報」打開才顯示（Designer 設定，見下方「一次性設定」） |

**不會自動變、要手動改的**：最新消息區塊標題「11月份最新直播」的月份（頁面文字，在 Designer 直接改）。

## 一、新增下一集（約直播前一個月）

1. 講師是新的：先到 **CMS → 三三分享會講師** 新增（名字、單位、照片正方形≥400px）。
2. **CMS → 三三分享會集數 → New item**，填：

| 欄位 | 填法 | 範例 |
|---|---|---|
| Name | 主題 | 長照職場性騷擾與照護界線 |
| Slug | `ep`＋集數 | `ep22` |
| 集數 | 數字 | 22 |
| 直播時間 | 台北時間當天 12:00 | 2026/11/18 12:00 |
| 日期大字 | `月.日` | 11.18 |
| 狀態 | **預告** | 預告 |
| 分類 | 四選一 | 機構經營管理 |
| 講師 | 選講師 | 吳孟姿 |
| 封面圖 | Canva 宣傳圖（16:9） | — |
| 卡片背景圖 | Canva 宣傳頁的**無字版**（刪字、logo、講師照後匯出 1600×900） | — |
| 講綱 | 三點「這集你會聽到」，用項目符號 | — |
| 直播／回放連結 | YouTube 直播網址（直播與回放同一個） | — |
| 開放簡報 | 先關 | 關 |

3. Save → **Publish**。
4. 改最新消息標題的月份（例：「12月份最新直播」）。

只要同時只有 **一筆**「預告」，最新消息卡與釘選條就會顯示它。

## 二、直播結束後：把這集移到「過去直播」

1. 打開該集，**狀態改「已播出」**（封面圖要有值）。
2. Save → Publish。這集會自動出現在「過去直播」對應分類，最新消息卡會換成下一筆「預告」。
3. 若下一集還沒建立，最新消息卡會顯示空狀態文字「下一集主題即將公布…」；建議直播結束前就先建好下一集。

## 三、換最新一集（提前公布、或日期調整）

- 最新消息卡永遠抓「預告」裡**直播時間最早**的那一筆。
- 要換顯示哪一集：改各集的「直播時間」或「狀態」。
- 同時有兩筆「預告」時，只會顯示日期較早的那一筆。

## 四、開放簡報下載（講師同意後）

1. 簡報轉 PDF，上傳到 OneDrive「三三分享會簡報」資料夾，檔名例：`EP22_長照職場性騷擾與照護界線.pdf`。
2. 分享 → 權限選「**擁有連結的任何人都可以檢視**」→ 複製連結。
   - 選單裡沒有「任何人」時，要請 IT 開放外部分享。
3. CMS 該集：貼到「**簡報下載連結**」，打開「**開放簡報**」→ Save → Publish。
4. LINE 官方帳號後台設定**關鍵字自動回覆**：關鍵字 `簡報EP22`（格式固定「簡報EP＋集數」），回覆內容放同一個 OneDrive 連結。
5. 換檔時，在 OneDrive 覆蓋同名檔案即可，連結不變。

## 五、查看表單名單

- Webflow：**Site settings → Forms**（或 Designer 左側 Forms），表單名稱「**三三分享會簡報索取**」。
- 欄位：索取集數（例「EP22 長照職場性騷擾與照護界線」）、姓名、Email、機構名稱、職稱、機構類型、目前使用智齡系統、想了解智齡系統、個資同意。
- 可匯出 CSV。同一人每月都會再填一次，可以用 Email 篩出**固定參加的人**；業務名單請篩「目前使用智齡系統＝沒有／不確定」且「想了解智齡系統＝勾選」。
- 表單通知信要寄到哪個信箱：在 Site settings → Forms 設定。

## 一次性設定（上線前，在 Designer）

1. 單集頁 Template 的課程簡報區塊（`section_sansan-deck`）設 **Conditional visibility：開放簡報 is ON**。API 寫入會被拒（component map conflict），只能在 Designer 設。
2. 確認表單裡的隱藏欄位（HTML Embed：`索取集數`）在 Designer 顯示為 CMS 欄位標籤；若顯示成文字 `{{wf …}}`，打開 Embed 用「+ Add Field」重新插入「集數」與「Name」。
3. Collection URL 改 `jubo-33-live-stream`（單集頁網址變 `/jubo-33-live-stream/ep22`）。
4. 單集頁其他區塊尚未設計前，Template 先維持 Draft；要上線簡報索取時再取消 Draft。
5. LINE QR code 目前是用 `lin.ee/Clf7lXr` 自己產生的；若行銷有官方 QR 圖，換掉 `sansan-line-qr.png`。
