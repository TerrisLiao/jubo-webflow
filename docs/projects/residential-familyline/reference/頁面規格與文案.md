## 1. 與日照安心寶的差異

| | 日照（`/products/familyline`） | 住宿型（本頁） |
|---|---|---|
| 情境 | 白天到中心、傍晚返家；家屬每天接送 | 長輩長期住在機構；家屬多半遠端，探視頻率低 |
| 主打功能 | 接送與簽到通知、家庭聯絡簿、心情、AI 文字生成 | 生理數值、外診紀錄、帳單收據、活動紀錄、照片花絮 |

## 2. 七項定義

| 項目 | 內容 |
|---|---|
| 1. 目標受眾 | 已使用或評估 Jubo 住宿型照護系統的護理之家、長照機構、安養機構的負責人與社工、行政 |
| 2. 單一轉換目標 | 洽詢住宿型安心寶加購（`/contact`） |
| 3. 核心價值主張 | 住宿系統裡已建檔的照護資料，家屬用 LINE 就能自己查；機構少回電話、少重複說明 |
| 4. 訪客疑慮 | 要不要另外整理資料？家屬會不會用？要不要自己申請 LINE？訊息費用？隱私與肖像權？能不能限制家屬看到的內容？ |
| 5. 信任證據 | 與住宿型照護系統同一套資料（不需另建）；顧問協助串接；目前**沒有住宿型客戶證言**，不借用日照證言 |
| 6. Section Flow | 見 §3 |
| 7. CTA | Primary：洽詢住宿型安心寶（`/contact`）；Secondary：了解住宿型照護系統（`/products/residential-care`） |

## 4. 文案草稿

> 用語：全頁統一用「住宿型安心寶」。「APP」不加：家屬端是 LINE 官方帳號，不需下載 App。

### 4-1 Hero

- Tag：住宿型照護系統加購
- H1：住宿型安心寶
- 副標：讓不在身邊的家屬，也看得見長輩在機構的日常
- 說明：住宿型安心寶串接 Jubo 住宿型照護系統，家屬在機構的 LINE 官方帳號就能查看長輩的生理數值、外診紀錄、帳單收據、活動與生活照片。機構不用另外整理資料，也能減少重複回覆家屬的時間。
- Primary：洽詢住宿型安心寶
- Secondary：了解住宿型照護系統

### 4-2 痛點 → 解法

H2：家屬想知道的事，不該都靠一通通電話

| 常見狀況 | 住宿型安心寶如何協助 |
|---|---|
| 家屬不常來探視，想知道長輩最近好不好 | 生理數值、活動與生活照片，家屬隨時用 LINE 查看 |
| 長輩外出就醫，家屬事後才來電詢問 | 外診的醫院、科別、時間與目的，系統建檔後家屬就查得到 |

| 用心安排的活動，家屬不容易看見 | 工作人員挑選照片分享，家屬可查看並下載 |

### 4-4 機構端怎麼運作

H2：資料照常在住宿系統建檔，家屬那端就同步更新

| 卡片 | 說明 |
|---|---|
| 照常記錄，自動同步 | 生理數值、外診時間表、繳費收據、活動紀錄照原本流程在住宿系統建檔，家屬端直接讀取，不用另外整理或轉貼。 |
| 照片由機構把關 | 活動照片不會自動上傳。工作人員挑選後再分享到住民檔案，家屬才看得到，兼顧住民隱私與肖像權。 |
| 一位家屬一組 QR Code | 在住民檔案的聯絡人產生 LINE 綁定 QR Code，家屬掃描並確認身分即可使用；綁定人數不限，也能隨時解除。 |
| 機構自己的 LINE 官方帳號 | 家屬加入的是機構的官方帳號，公告與家屬溝通集中在同一個入口。 |

### 4-5 導入流程

1. **確認方案**：確認機構使用 Jubo 住宿型照護系統，並加購住宿型安心寶。
2. **建立 LINE 官方帳號**：機構申請 LINE 官方帳號（免費開設），已有帳號可直接使用。
3. **完成串接**：將顧問加為官方帳號管理員，由顧問完成系統串接。
4. **家屬綁定**：家屬加入機構 LINE、掃描綁定 QR Code，就能開始查看長輩資訊。

### 4-6 常見問題（草稿，來源：操作手冊 QA 與推播說明）

1. **家屬需要下載 App 嗎？**　不需要。家屬用平常使用的 LINE 加入機構官方帳號，完成綁定後就能查看。
2. **一位住民可以綁定幾位家屬？**　不限人數。其他家屬想了解住民照護情形，經機構確認身分與需求後即可協助綁定。
3. **機構可以限制家屬查看的功能嗎？例如不顯示生理數值？**　目前尚未提供個別功能隱藏設定。建議以提供家屬完整且適當的照護資訊為原則。
4. **收據可以設定只有特定家屬能看嗎？**　只要完成綁定的家屬，都能查看住宿型安心寶提供的功能與資訊。
5. **活動照片會自動出現在照片花絮嗎？**　不會。活動照片由工作人員判斷並手動分享後，才會出現在家屬端。建議分享前先確認照片內容與相關人員的肖像使用同意。
6. **使用 LINE 官方帳號會產生訊息費用嗎？**　家屬點選選單查詢資料不計入推播則數；機構公告、帳單推播等主動發送的訊息會計入 LINE 官方帳號的訊息則數，免費額度與加購方案依 LINE 官方帳號方案為準。
