## 1. 與日照安心寶的差異

| | 日照（`/products/familyline`） | 住宿型（本頁） |
|---|---|---|
| 情境 | 白天到中心、傍晚返家 | 長期住在機構；家屬多半遠端 |
| 主打功能 | 接送與簽到通知、家庭聯絡簿、心情、AI 文字生成 | 生理數值、外診紀錄、帳單收據、活動紀錄、照片花絮 |
| 家屬綁定 | 家屬重新驗證開通 | 每位家屬一組 QR Code，人數不限，可解除綁定 |
| 銷售方式 | — | 住宿型照護系統的**加購**項目 |

### 4-2 三張 UI 卡

| 圖 | 標題 | 說明 |
|---|---|---|
| UI Card - 生理數值隨時查看 | 生理數值隨時查看 | 體溫、血壓、脈搏等近兩個月紀錄，偏高偏低一眼看出。 |
| UI Card - 外診紀錄不漏接 | 外診紀錄不漏接 | 就醫院所、科別、時間與目的，長輩外出看診家屬同步掌握。 |
| UI Card - 帳單收據線上查 | 帳單收據線上查 | 近一年收據與繳費狀態清楚列出，減少逐一通知。 |

### 4-3 三個主題（scroll card）

**健康狀況隨時掌握**（圖：住宿型安心寶 – 健康狀況隨時掌握）
- 生理數值趨勢：體溫、血壓、脈搏、血糖、體重近兩個月紀錄，用趨勢圖看懂變化
- 異常一眼看出：偏高、偏低數值直接標示，家屬不必自己判讀
- 外診紀錄同步：近半年就醫院所、科別、時間與目的，長輩外出看診不再錯過

**生活點滴即時分享**（圖：住宿型安心寶 – 生活點滴即時分享）
- 照片花絮：近半年生活照片與活動照片，家屬可查看並下載
- 活動紀錄：近一年參與過的活動一覽，了解長輩在機構的生活安排
- 照片由機構把關：活動照片不會自動上傳，工作人員挑選後才分享，兼顧住民隱私與肖像權

**家屬綁定簡單安心**（圖：住宿型安心寶 – 家屬綁定簡單安心）
- 一位家屬一組 QR Code：從住民檔案產生綁定 QR Code，家屬在 LINE 掃描、確認身分即可使用
- 綁定人數不限：其他家屬經機構確認身分後即可綁定，也能隨時解除綁定
- 資料自動同步：生理數值、外診、收據、活動照常在住宿系統建檔，家屬端直接讀取，不用另外整理

### 4-4 CTA

- 主要按鈕：立即洽詢 → `/contact`
