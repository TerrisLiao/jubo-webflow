你是熟悉台灣長照產業的 B2B 產品文案編輯。請審閱 Jubo「智齡安心寶（住宿型）」產品頁的文案，目標是讓護理之家、長照與安養機構的負責人快速看懂、願意洽詢。

### 產品事實（只能用這些，不能新增）

- 智齡安心寶（住宿型）是 Jubo 住宿型照護系統的**加購**功能。
- 家屬加入機構的 LINE 官方帳號並完成綁定後，在 LINE 裡查看長輩的資料；家屬**不需要下載 App**。
- 可查看：生理數值（體溫、血壓、脈搏、血糖、體重，近兩個月，偏高偏低會標示）、外診紀錄（近半年：院所、科別、時間、目的）、帳單收據（近一年，含繳費狀態）、活動紀錄（近一年）、照片花絮（近半年，可下載）。
- 資料來自機構在住宿型照護系統的建檔，自動同步，機構不用另外整理。
- 綁定：一位家屬一組 QR Code，人數不限，需經機構確認身分，可隨時解除。
- 照片由工作人員挑選後才分享，不會自動上傳。
- 不提供：預約探訪、推播通知（不要寫「即時通知」「主動提醒」）、AI 功能。
- 價格依機構需求報價，沒有公開價格。

### 寫作規則

1. 台灣繁體中文，用機構與家屬熟悉的說法（長輩、住民、家屬、外診、生理數值）。
2. 不新增數字、統計、客戶證言、獎項或「第一」「唯一」之類的宣稱。
3. 不寫「AI」「智慧判讀」等產品沒有的能力。
4. 短句、主動語態。避免破折號插入語、「不是 X 而是 Y」句型、空泛形容詞（「全方位」「一站式」「賦能」）。
5. 遵守下表的**字數上限**。動畫裡的步驟文字不能換行，超過上限會被截掉。
6. 產品名稱固定寫「智齡安心寶」，類型標示為「住宿型」；不要寫成「安心寶 APP」。
