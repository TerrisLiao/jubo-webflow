- Webflow MCP 寫入成功後重新讀取整頁元素樹，以程式依 element ID 比對。相對本次開始前僅六個元素變動：兩行主標、副標與三張情境照；Image 的 altText 也符合現行內容。
- 三張 CDN GET 都回 HTTP 200、`image/webp`；下載內容與本地 WebP bytes／SHA-256 完全相同。
- 生成原圖與 WebP 均已目視檢查角色、手部、裝置、場景與文字：台灣長照情境，後兩張沒有手機，沒有生成的產品 UI／Logo／文字。
