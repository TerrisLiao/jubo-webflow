## 1. 起因

主管在較窄螢幕上看 `/customer-stories/*`，左側「更多成功故事」佔掉大量版面，主文只剩約一半。

## 2. 現況實測

方法：Playwright 開正式站 `customer-success-stories-jubostory14`，讀 `getBoundingClientRect()`。

| 視窗 | 左欄 | 欄距 | 主文欄 | 內文字寬（18px） | 約略字數／行 |
|---|---|---|---|---|---|
| 1024 | 336 | 128 | **432** | **304** | **≈17** |
| 1280 | 336 | 128 | 688 | 560 | ≈31 |
| 1366 | 336 | 128 | 774 | — | — |
| 1440／1536／1920 | 338 | 128 | 846 | 718 | ≈40 |

結構（Webflow 輸出）：

```
.container-large
└ .customer-story_template-component            grid，兩欄
  ├ .customer-story_template-left-wrap          左欄，≥992 顯示
  │ └ ._2col-sticky_headline-wrap               sticky（共用 class）
  │   └ .customer-story_other-content-wrap      更多成功故事（5 筆＋顯示更多）
  ├ .customer-story_template-right-wrap
  │ ├ .customer-story_template-headline-wrap    h1.client-story_template-h1 ＋ img.client-story_template-img
  │ └ .customer-story_content-wrap              白色閱讀卡（.richtext）
  └ .customer-story_other-content-wrap.is-mobile  ≥992 display:none；≤991 顯示在文末
```

問題：

1. 左欄＋欄距固定約 464px，螢幕越窄佔比越高；992–1279 最嚴重（1024 時內文每行約 17 字）。
2. 左欄 sticky，整篇閱讀期間都在主文左側爭奪注意力，且讀序先於標題。
3. 文末版本（`.is-mobile`）早已存在，只是桌機隱藏。

## 3. 參考研究（Mobbin）

| 做法 | 代表 | 要點 |
|---|---|---|
| 單欄＋文末延伸閱讀 | [Whereby](https://mobbin.com/sites/sections/8f8404c1-8369-4a31-8adc-eac383f475d9)、[Zendesk](https://mobbin.com/sites/sections/624330e1-b370-46c8-ae0d-fb6faf41183d)、[Dropbox](https://mobbin.com/sites/sections/3af6a5fe-ee5c-491d-871a-e2579f5efd05) | 其他故事一律在文末 3–4 卡 |
| 主文寬＋右側窄欄放客戶資訊 | [Tailscale](https://mobbin.com/sites/sections/84f94fa1-216c-40e9-aa21-d4b6e8039f5b)、[Dovetail](https://mobbin.com/sites/sections/93f952db-3d57-42d4-a50b-302a4b4fab50)、[Vercel](https://mobbin.com/sites/sections/3a3e479b-766c-474f-923a-b3436085dc2c) | 側欄約 20–25%，放產業／規模／CTA |
| 三欄（客戶資訊＋主文＋目錄） | [Attio](https://mobbin.com/sites/sections/17d20552-2b39-4321-9e15-8c0625596ec8) | 需要額外 CMS 欄位 |
| 開頭成果數字 | [Jasper](https://mobbin.com/sites/sections/69d12cd5-407c-4fa3-a4d8-a765cadeb9b0) | 需要可量化成果 |

觀察：取樣的 B2B 客戶故事頁沒有把「其他故事清單」與主文並排；側欄若存在，放的是該客戶資訊或 CTA。

行長依據：[WCAG 2.1 Visual Presentation](https://w3c.github.io/wcag21/understanding/visual-presentation) 建議 CJK 每行 ≤40 字（AAA 上限，不是最佳值）。

## 4. 方案一規格

```
[ 標題＋封面圖       max-width 64rem（=container-medium 寬）]
     [ 內文白卡    max-width 50rem → 字寬 672px ≈ 37 字/行 ]
[ 更多成功故事 3 卡（16:9 圖＋標題）＋「看全部成功故事」 max-width 64rem ]
[ 既有 section_cta ]
```

模擬結果（正式站注入 CSS，非 Webflow 輸出）：

| 視窗 | 標題／封面 前→後 | 內文字寬 前→後 |
|---|---|---|
| 1024 | 432 → 896 | 304 → 672 |
| 1280 | 688 → 1024 | 560 → 672 |
| 1440 | 846 → 1024 | 718 → 672 |

1440 以上內文字寬略縮（≈40 → ≈37 字），是刻意收在 40 字上限內。

### 4-1. 模擬用 CSS（僅作規格參考，不是部署碼）

```css
@media (min-width: 992px) {
  .customer-story_template-component { grid-template-columns: minmax(0, 1fr); row-gap: 6rem; justify-items: center; }
  .customer-story_template-left-wrap { display: none; }
  .customer-story_template-right-wrap { width: 100%; max-width: 64rem; align-items: center; }
  .customer-story_template-headline-wrap { width: 100%; }
  .customer-story_content-wrap { width: 100%; max-width: 50rem; }
  .customer-story_other-content-wrap.is-mobile { display: flex; flex-direction: column; gap: 2rem; width: 100%; max-width: 64rem; }
  /* 卡片化：模擬時用子孫選擇器；Webflow 內請改用 combo class，見 4-2 */
  .is-mobile .customer-story_cms-list { display: grid; grid-template-columns: repeat(3, minmax(0, 1fr)); gap: 2rem; }
  .is-mobile .single-customer-story_wrap { flex-direction: column; gap: 1rem; }
  .is-mobile .img-mask, .is-mobile .customer-story_image-wrap { width: 100%; aspect-ratio: 16 / 9; }
}
```

### 4-2. Webflow 實作步驟（待授權）

1. `.customer-story_template-component`：main 斷點改單欄、置中，row gap 綁間距 Variable。
2. `.customer-story_template-left-wrap`：main 斷點 `display:none`。**不要改 `._2col-sticky_headline-wrap`**，它是 `section_2col-sticky` 等區塊共用的 class。
3. `.customer-story_template-right-wrap` max-width 64rem；`.customer-story_content-wrap` max-width 50rem（保留既有 padding／圓角／陰影）。
4. `.customer-story_other-content-wrap.is-mobile`：main 斷點改為顯示；清單改 3 欄 grid。
5. 卡片直排：在清單項目內加 combo class（例如 `.single-customer-story_wrap.is-card`），**不改名**、不刪既有 class。`.single-customer-story_wrap`／`.customer-story_image-wrap`／`.customer-story_headline-wrap`／`.customer-story_pagination` 被 Slater 鎖定（hover 縮放、載入全部後隱藏分頁），見 [Slater 鎖定清單](../../../../custom-code/slater-selectors.md)。
6. Collection List 筆數由 5 改 3（文末與手機共用同一份清單）；分頁「顯示更多」換成連到 `/customer-success-stories` 的「看全部成功故事」，沿用既有 `cta-button` 樣式。
7. 文末放既有 `section_cta`（首頁、`/company` 已在用），不新建 CTA。
8. 四斷點讀回；992–1279、≤991、≤767 各截圖；確認圖說玻璃條、引言卡、封面 aspect-ratio 規則（`_cover-aspect-story.css`）仍正常。

### 4-3. 已知限制與附帶發現

- 模擬時文末卡片縮圖左緣被 `object-fit: cover` 裁切（封面字樣「Jubo」被切掉一角），實作時需確認 `.img-mask` 比例與素材一致。
- 1024px 時導覽列 logo 與「找到適合你的方案」幾乎相貼，與本案無關，另案處理。
- 手機版本已在文末，方案一不改 ≤991 的版面，只會因筆數改 3 而變短。
- 未測 Safari 與實機；Webflow 實際輸出需在 Designer／Preview 目視確認。
