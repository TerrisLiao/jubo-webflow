# 07 新鮮度 SLA 與 30 天回檢

依 Notion `📌 AEO 官網工作文章`（2026-08-31）：「**新鮮度是競爭槓桿**」、「95% 的 ChatGPT 引用來自過去 10 個月內更新過的頁面」。小品牌可藉此在特定長尾題目超越大品牌。

核心規則：**更新必須新增證據與變更說明，不能只改日期。**

## 新鮮度 SLA

Notion 點名要有內容所有人與更新 SLA 的四個主題。**內容所有人待 Terris 指派**（`05_` 的 P2-4）。

| 主題 | 為什麼需要 SLA | 建議更新週期 | 內容所有人 | 上次更新 | 下次到期 |
|---|---|---|---|---|---|
| 長照相關法規 | 法規異動直接讓內容失效 | 季度，或法規公告後 2 週內 | 待指派 | | |
| 機構評鑑 | 評鑑指標與時程逐年調整 | 年度，評鑑公告後 | 待指派 | | |
| 資安 | 要求與威脅情勢變動快 | 半年 | 待指派 | | |
| 長照 3.0 | 政策推進中，尚未定案的部分多 | 季度 | 待指派 | | |

⚠️ 長照 3.0 有政策未定案的部分。依發布閘門規則，**未完成的政策更新不得預先寫成結論** —— SLA 到期時如果政策仍未定案，就記錄「查核過、無異動」，不要為了「有更新」而寫推測。

## 30 天回檢

Notion 規則：「發布後第 30 天檢查實際曝光查詢；排名 4–15 且 CTR 偏低時，優先更新 title、meta、首段答案與內部連結。」

### 流程

1. 【本機】從 CrawlSEO 撈該 URL 的 GSC 數據：clicks、impressions、CTR、平均排名、實際曝光查詢
2. 判斷：

| 情況 | 動作 |
|---|---|
| 排名 4–15 且 CTR 偏低 | **優先修 title、meta description、首段答案、內部連結**（不是重寫全文） |
| 排名 > 15 | 內容深度或主題匹配有問題，回頭看實際曝光查詢是否與主關鍵字一致 |
| 曝光查詢與預期主關鍵字不符 | 選題或標題訊號錯了，考慮調整主關鍵字而非加字數 |
| 有 cannibalization | 檢查是否有舊文沒併乾淨，補 301 |

## Publish 前驗證清單

每支 pillar、每篇改寫都要跑完。
