### Section 2｜痛點

- H2：`每月核銷，時間都花在哪裡？`
- 導言：`額度對不對、次數對不對、格式有沒有錯。這些不難，但年復一年，每個月都得再來一次。`

| # | H3 | 內文 |
|---|---|---|
| 1 | 額度與次數，一筆一筆對 | 每月申報核銷時，仍需回到照管平台逐項比對額度與服務項目次數。件數一多，一個上午就過去了。 |
| 2 | 照顧計畫更新，得手動搬一次 | 個案照顧計畫一有異動，就要到照管平台下載，再匯入系統，兩邊來回切換。 |
| 3 | 格式錯了，整份重來 | 匯入時常因檔案格式不符被退回，同一份資料反覆處理，錯誤也不容易一眼看出來。 |
| 4 | 全部擠在申報期 | 比對與匯入都壓在同一段時間，而前線的服務安排與個案聯繫並不會因此變少。 |

### Section 3｜對比表

- H2：`核銷比對，從逐筆核對變成一鍵產表`
- 導言：`手動比對能查到單一個案的額度，但得一個一個開。iBee 讓你一次勾選多位個案，自動跑完比對並產出報表，差異在哪裡一眼看到。`
- 欄位標題：`iBee 照管小幫手` ／ `手動作業`

| 列 | iBee | 手動作業 |
|---|---|---|
| 比對方式 | 勾選個案，<br>系統自動比對 | 逐案開啟照管平台，<br>人工核對 |
| 產出結果 | 自動產出比對分析報表 | 自己整理成表格 |
| 照顧計畫 | 點個案姓名，<br>自動取得並匯入 | 手動下載再上傳，<br>可能格式錯誤 |
| 每月核銷 | 先看報表，<br>再處理差異 | 先花時間核對，<br>才看得到差異 |

- 導言：`不需要另外採購，也不用等排程導入。`

- 補充提示：`完整操作手冊：登入 i照護系統 → 左側選單 → 操作手冊 → iBee 照管平台小幫手`

### Section 5｜三個改變

- H2：`三個讓照管人員有感的改變`
- 導言：`iBee 的角色是協助與支持照護團隊，專業判斷始終在承辦人員手上。`

| # | H3 | 內文 |
|---|---|---|
| 1 | 一、核銷比對自動化 | 勾選個案、一鍵比對，系統自動產出分析報表，不再手動逐筆核對，大幅縮短核銷作業時間。 |
| 2 | 二、照顧計畫一鍵匯入 | 點擊個案姓名，自動取得照管平台的照顧計畫並匯入系統，不必手動下載，也少了格式錯誤反覆處理的來回。 |
| 3 | 三、時間回到照顧現場 | 重複的比對與資料搬運交給 iBee，照管人員把心力放回個案溝通與服務安排。 |

### Section 7｜FAQ

- H2：`常見問題`
- 導言：`關於啟用方式、支援環境與資料來源，這裡整理常見問題。`

| Q | A |
|---|---|
| Q1｜要另外付費嗎？ | iBee 是 i照護系統的內建功能。現有用戶依上述 3 個步驟完成安裝，就能開始使用。 |
| Q2｜為什麼一定要用 Google Chrome？ | iBee 以 Chrome 擴充工具的形式運作，需要在 Chrome 環境下才能與照管平台連動，其他瀏覽器目前不支援。 |
| Q3｜擴充工具要去哪裡安裝？ | 使用 Chrome 登入 i照護系統後，系統會在畫面上引導安裝，依指示完成即可，不需要自行搜尋。 |
| Q4｜為什麼要保持照管平台登入？ | iBee 是代替你到照管平台讀取資料，沿用你本人的登入狀態與權限。一旦登出，iBee 就取不到資料。 |
| Q5｜比對結果會直接送出申報嗎？ | 不會。iBee 產出的是比對分析報表，供你確認差異；申報與送出仍由承辦人員自行判斷與操作。 |
| Q6｜個案資料會外流嗎？ | iBee 讀取的是貴單位在照管平台與 i照護系統中既有的資料，沿用現行帳號權限，僅具權限者可查閱。詳細的資料處理與保護說明，可與專屬窗口聯繫。 |
| Q7｜會取代照管人員的工作嗎？ | 不會，也不該。iBee 減少的是重複的比對與資料搬運，讓照管人員把時間放回個案溝通、服務安排與專業判斷。 |
| Q8｜遇到問題要找誰？ | 請在官方 i照護顧問 LINE 群組留言，並附上發生經過、時間與螢幕截圖，顧問團隊會依序排程處理。i照護 客服電話：02-5568-6435 #335。 |

三個選項：
1. 維持現狀，接受 iBee 頁掛著 `amy-lens_*` class（最省事，但語意不對）
2. 另開 `ibee_*` folder，複製樣式後逐一改掛（乾淨，但工作量大且要重新對四個斷點）
3. 把這組 class 正名為中性的 `ai-product_*`，兩頁一起換（最正確，但屬跨頁改動，風險最高）

**建議選 1 先上線、之後排程處理 2**，但這是 Terris 的決定。
