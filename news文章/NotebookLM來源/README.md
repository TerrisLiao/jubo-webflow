# NotebookLM 來源文件

給 NotebookLM（或其他 AI 工具）當來源用的彙整文件，內容涵蓋 115 年住宿式機構補助新制。

## 檔案

| 檔案 | 說明 |
|---|---|
| `住宿式機構補助115年新制_資料彙整.pdf` | **要上傳到 NotebookLM 的檔案**（A4、7 頁） |
| `住宿式機構補助115年新制_資料彙整.html` | PDF 的內容來源，要改內容改這份 |
| `build_pdf.py` | HTML → PDF 轉換腳本 |

## 內容結構

1. **政策事實整理** — 金額與三類資格、適用機構、按月認列天數門檻、住院期間算法、1-8 月過渡期、申請期限（中央兩段 + 各縣市提前）、免重新申請條件、不予補助情形、應備文件、經費、常見誤解澄清
2. **顧問說明整理** — 2026-09-17 內部會議逐字稿重點
3. **Jubo 住宿式系統能做到什麼** — 年度收住日數統計現況、對應新制的三項能力、9/29 月份限定查詢、現階段仍需人工的部分
4. **官網內容現況與行動建議** — 文章 Draft 現況、站上 CMS 實況、8 項建議（依優先序）
5. **待確認事項與風險**
6. **資料來源清單**

## 重新產生 PDF

```bash
python3 build_pdf.py 住宿式機構補助115年新制_資料彙整.html 住宿式機構補助115年新制_資料彙整.pdf
```

需要 `reportlab`（`pip install reportlab`）與系統中文字型
`/usr/share/fonts/truetype/wqy/wqy-zenhei.ttc`。

## 注意

- 這份是**內部參考文件**，不是對外文案。對外溝通前所有金額、日期與法規條文需人工複核。
- 各縣市 1-8 月收件期限持續變動中，使用前請確認是否已更新。
