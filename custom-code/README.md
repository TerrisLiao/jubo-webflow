# 客製程式與工具

| 類型 | 位置 | 狀態 |
|---|---|---|
| CMS 維護原始碼 | [cms-article](cms-article/README.md) | master 已含，產物可重建 |
| Schema 模板 | [schema-templates](schema-templates/README.md) | 從資安分支匯入；部署依來源與新讀回驗證 |
| 聯絡頁導流 | [contact 專案](../docs/projects/contact/README.md)、contact-router.html | 匯入原始碼，本輪未部署 |
| 資安工具／程式 | [security-mg](security-mg/README.md) | 源分支工具，本輪未部署 |
| 無障礙工具 | [a11y-audit](a11y-audit/README.md) | 原始 baseline 另見外部索引 |
| 品牌 SVG | [n-copilot](brand/n-copilot/README.md) | SVG 保留；AI／PDF 來源另見外部索引 |
| llms.txt | [seo/llms.txt](seo/llms.txt) | 網站根目錄 llms.txt 的維護來源；Webflow MCP 無法寫入，需在 Site settings → SEO 手動貼上 |
| POC | poc/ | 實驗；不是全站已採用程式 |
| archive/ | 舊版本 | 只作追溯，不直接復原 |

修改前查專案 deployment、Page／Embed ID、source SHA。改 Git 不等於改 Webflow；部署需範圍明確且有授權。共用 Slater 不在一般頁面工作範圍。

[大型來源索引](../docs/workflows/external-artifacts.md)；[匯入清單](../docs/workflows/import-manifest.json)。
