N.Copilot 標誌能怎麼動

四種做法並排，點各自的「重播」看一次。素材是從原稿 .ai 讀出的向量， 幾何沒有改過。中間那顆星是兩片翼之間的負空間，不是獨立物件 —— 所以下面四種都沒有動到星星本身。

A ／ 兩翼合攏，星芒長出來

兩片翼從對角飛進來、合攏的那一瞬間，中間的星自己出現。這是唯一一種利用「星是負空間」這個特性的做法 —— 其他家的 logo 動畫做不出這個，因為他們的星星是畫上去的。

B ／ Aurora 掃光

標誌填的是品牌的 Aurora 漸層（停點是從原稿色票取樣的，不是我挑的），一道光斜斜掃過去。適合 hover 與進場，也最符合「highlight 走 gradient」這條。

不改幾何hover／進場純 SVG + CSS 也能做

C ／ 描邊繪出

輪廓先一筆畫出來，再填色進去。用 pathLength="1" ＋ stroke-dashoffset，不需要 DrawSVGPlugin。最安靜的一種，適合品牌頁的開場。

D ／ 拿 logo 當 thinking 指示器

使用者等回答的那兩秒，是整頁注意力最集中的時刻。放三顆通用的灰點太浪費了 —— 放你們的標誌在轉，那兩秒就變成品牌曝光。

星星為什麼不能單獨動
  • 標誌只有 2 條 path，各 217.6 × 90，互為 180° 對稱 —— 就是兩片一模一樣的翼。
  • 中間的四角星是這兩塊之間沒被填到的地方，不是一個可以選取的物件。
  • 所以「星星單獨呼吸／旋轉／morph 成三顆點」做不到，除非另外畫一條星星 path 疊上去。
  • 那等於改動原稿幾何，依 00_AI工作守則.md §6-8 要先問過，我不會自己動。
