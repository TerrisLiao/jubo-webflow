在 Webflow 上怎麼落地：IX3 的邊界在哪

照我拆 Noura 那份 IX3 實際資料所看到的能力範圍判斷。

這一段IX3怎麼做
星芒呼吸、旋轉、縮放、淡入淡出可以IX3 transform ＋ opacity，target 用 class 或 attribute
四道光線射出（含 stagger）可以IX3 scale ＋ stagger，Noura 就是這樣做的
光點 bloom可以IX3 scale ＋ opacity
生長遮罩不行要縮放 SVG <mask> 裡的元素，IX3 碰不到 SVG 內部節點。頁面層 GSAP（09 §3）
漸層停點變色不行要 tween stop-color 屬性。GSAP 一行，IX3 沒有這個能力
整體 scale 站定可以IX3 transform，但 elastic 那種 easing IX3 的預設清單裡沒有
idle／thinking／success 切換不行IX3 沒有狀態機。頁面層 JS，照 §10-0-2
捲動觸發、hover、click可以IX3 的強項，scrollTrigger 的 start／end／scrub 都能調

結論：這支動畫主體走頁面層 GSAP，IX3 負責周邊的捲動與 hover。 這不是退而求其次 —— 09 §3 本來就規定新動畫寫在頁面層 custom code。 真正要注意的是：同頁開 IX3 會多載一份 Webflow 自己的 GSAP，跟站台 head 那份重複， 這就是要在 /ai-lab 量的那件事。

幾件講清楚的事

  • 最後一格一定是原稿標誌。生長是遮罩推出來的，遮罩推滿之後畫面上就是官方那兩條 path，不會因為動畫而變形。
  • 生長中外形是變的 —— 這是 Terris 2026-09-16 明確授權的（可以改幾何，只要最後長成正確的 logo）。
  • 星芒呼吸有兩種：「光暈」在負空間疊一顆發光的星，原稿不動；「幾何」用 mask 把星挖成洞，呼吸時標誌外形會脹縮。切過去比較看看。
  • 星形不是憑感覺畫的：從原稿量出負空間兩個尖端 —— 上 (115.29, 36.45)、下 (132.55, 83.24) —— 得到中心 (123.9, 59.8)、短軸 25、主軸 −20.1°（與兩翼長軸一致），再生成四角星。
  • 要完全不加光的官方靜態標誌，把 idle 的 a0 設成 0 就好。
