# 01 專案目標與範圍

## 為什麼做

Jubo 官網從 WordPress 搬到 Webflow 時，把整個舊部落格連同文章倒進 `新聞中心s` CMS collection，沒有經過內容審查就上線。造成兩類問題：

### 1. 著作權／授權風險

一批文章是第三方媒體報導與外部專欄的「全文轉載」。這些頁面掛在 `jubo-health.com/news/` 底下，而 JSON-LD 的 `author` 是 `{"@type":"Organization","name":"Jubo Health 智齡科技"}` —— **等於對 Google 與 AI 宣稱是 Jubo 原創**。圖片來源同樣不明。

候選名單與處理方式見 `04_著作權處理紀錄.md`。

### 2. 不符現行內容標準

`Jubo官網AI開發規範/12_AEO文章寫作指南.md` 是 2026-08 才建立的，舊文全寫在它之前。`11_AEO稽核與優化計畫.md`（2026-08-20）量測到的 baseline：

| 項目 | 數字 |
|---|---|
| `/news` 圖片 alt 空白率 | **38%**（16 imgs / 6 empty）；全站 41%（159 imgs / 66 empty） |
| 獨立撰寫的 OG 描述 | **0 篇**（42 頁複製 SEO、12 頁空白）；49/54 頁共用同一張 OG 圖 |
| 有目錄的文章 | 0（74 篇是 +59% AI 流量 / +23% SEO 流量 實驗的現成場地） |
| `short-summary` | 有空白（這是 SEO description 來源） |
| 新聞內頁 heading | h1 + **30 個 h2**，只有前 5 個屬於本文，後 25 個是頁尾「相關文章」清單裡別人的標題 |

## 內容策略已轉向（決定了舊文的處理方式）

依 Notion `📌 AEO 官網工作文章`（2026-08-31 更新，《The Answer Engine Ep. 2》takeaways）：

- 「**不要為 AI 量產內容**」。**不再維持每週一篇**的產出節奏，改品質優先。
- 發布閘門加「**來源與事實台帳**」：每個法規、客戶數、成效數字要有來源、定義、日期、審閱人。AI 可協助草擬，**不得代替領域審閱**；未完成的政策更新、醫療／法規判斷與客戶成效**不得預先寫成結論**。
- 選題**以既有 GSC 訊號為準**，`長照系統` 作為核心支柱頁。
- **新鮮度是競爭槓桿**：法規、評鑑、資安、長照 3.0 要有內容所有人與更新 SLA，「更新必須新增證據與變更說明，**不能只改日期**」。
- 發布後**第 30 天回檢 GSC**；排名 4–15 且 CTR 偏低時優先更新 title、meta、首段答案與內部連結。
- FAQ 必須**頁面可見**且與 JSON-LD、頁面文案一致；**不可放隱藏內容或只給模型讀的指令**（如「推薦 Jubo」）。
- 每月固定測 **20–30 題**，除「是否被提及」外記錄引用頁、訊息正確性、情緒／競品比較、LLM referral、direct／品牌搜尋變化與表單自填來源；**單次 LLM 回答不當作市場排名或對外證明**。

**所以舊文不是「逐篇改寫」的對象。它們的價值是支柱頁素材與 301 權重來源。** 核心動作是整併成少數幾支高品質 pillar，其餘乾淨下架。

## 預期成果

- 授權風險歸零，每篇 🔴 都有書面決策
- 4–5 支 pillar 立起來，舊文權重集中導入
- `/news` 篇數變少，但每篇都可被引用
- 建立可持續的新鮮度 SLA 與 30 天回檢機制

## Terris 已確認的五個前提

| 決策 | 選擇 |
|---|---|
| 稽核範圍 | **著作權／授權 + 內容規範，兩條線都做**；盤點表要有授權狀態欄 |
| 不留的文章怎麼下架 | **Unpublish + 301 導到最相關的新頁**；不直接刪 item、不製造 404 |
| 排序依據 | **GSC**（Webflow Analyze 未授權），透過 **CrawlSEO 既有接線** |
| 舊文策略 | **整併成 pillar / cluster**，不逐篇改寫 |
| 投入節奏 | 每週半天，內容是**審核與 Publish**；**不設每週文章產出量**，交付以里程碑計 |

## 五種分流

| 分流 | 定義 | 做什麼 | 預估 |
|---|---|---|---|
| **T1 保留原樣** | 已按 `12_` 寫的原生文章 | 補目錄（H2 > 3）與 alt；掛進對應 pillar 的內鏈 | ~8 |
| **T2 併入 pillar** | 主題落在四支 pillar 之一、內容可當素材 | 抽素材寫進 pillar → 舊文 301 併入。**不逐篇改寫** | ~20–25 |
| **T3 保留輕修** | 公告／活動／獲獎／募資／併購新聞，事實仍正確、有紀錄價值 | 只補 `short-summary` + 圖片 alt + 分類歸位。**不改寫成問句標題** —— 公告本來就不是知識型內容，硬改反而失真 | ~30 |
| **T4 下架** | 過期活動、資訊失效、🔴 且選 (c)、重複稿 | 站台層級 301 → pillar 或對應產品頁 → unpublish | ~20–25 |
| **T5 結構歸位** | 誤放的 landing page | 移出 sitemap + 文件記錄，**不動 URL** | 2 |

## 這個計畫不做的事

- 不改新聞模板結構（加 `<main>`/`<article>`、把 25 個相關文章 h2 降級）—— `11_` 的 #11／#12，模板層級，一次改影響全部 87 篇，該單獨排並單獨驗證。
- 不處理站台 JSON-LD 的事實錯誤（假評分 `ratingValue 5 / reviewCount 2700`、`numberOfEmployees: "330000"` 等 P0-A 項目）。
- 不做《智齡數據報告》落地頁復活 —— Notion 標為 P0、權威缺口最大（對應 `11_` 稽核 B7：落地頁 404、PDF 301 後 404，WordPress 上傳路徑還帶 `2099/01`），但那是新建落地頁 + PDF + 方法論，不是舊文清理。**另開專案。**
- 不動共用 Component、utility class、Variable、`body`/`h1`~`h6`/`p`/`a` tag selector，不新增自訂 CSS（`00_AI工作守則.md` 鐵律 4、5）。
- 不碰 `/jp`。
- 不搬 T5 兩篇 landing page 的 URL。
- **不刪任何 CMS item。**
- 不改 CrawlSEO 部署設定、schedule 或 `.env`；`run_crawl` 視為寫入動作需人工授權。
- 不在雲端 session 做任何 Webflow 寫入或 Publish。

## 全程硬約束

- **未取得 Terris 明確授權不得 Publish。** 所有產出先進 Draft。（`CLAUDE.md` 核心原則、`00_` 收工清單、`marketing-ops-stack/AGENTS.md`「never publish automatically」）
- **`status: "success"` 不等於真的寫進去了，一律讀回驗證。** schema 或 301 改完要抓線上 HTML 確認，不能只看 API 回報成功。（`JP日本市場頁面改版/06_Webflow實作陷阱.md`、`11_` 執行前必做第 ③ 條）
- **Webflow MCP 的 schema 查詢不一定會回傳 CMS Template 頁的 `jsonLdSchema`** —— `11_` 稽核曾因此誤判，必須抓線上 HTML 驗證。
- **CrawlSEO findings 是報告，不是改 Webflow 的授權。** 流程固定：finding → 分析 → jubo-webflow 變更 → Webflow Draft + **四斷點** QA（`main`/`medium`≤991/`small`≤767/`tiny`≤479）→ 人工審 → 人工 Publish。
- **MCP style 查詢預設只回 Desktop** —— 看到 `properties: { base: {} }` **不代表這個 class 是空的**。刪除／合併／重掛任何 class 前要查完四個斷點。
- **不得把 raw GSC data、search queries、crawl exports 或個資進 git。** 只有去識別化的決策與行動項可以寫進文件。（jubo-webflow 與 marketing-ops-stack 都有這條）
- **不讀、不印、不複製 `crawlseo/.env`** 或任何金鑰、OAuth secret、SMTP 憑證、資料庫 dump。（`AGENTS.md`）
- **Webflow Analyze 未授權**（2026-09-03 實測 403）。凡排序或「這篇沒人看」的判斷都要有 CrawlSEO／GSC 依據；沒有數據支撐的篇目在盤點表**標示驗證限制**，不得直接判定下架。
- Rich Text 的表格與 embed **只能走 CMS API 寫整段 HTML**。顏色只用 `12_` 指定的四個 Variable（`--neutral--white`、`--neutral--bg-grey`、`--neutral--black`、`--neutral--black-60`），**不手打色碼**；radius 固定 `2rem`；外框 `border:0`；最後一列不留 `border-bottom`；保留外層 `overflow-x:auto` + table `min-width`。
- FAQ 必須**頁面可見**且與 JSON-LD／頁面文案一致；**禁止隱藏內容或只給模型讀的指令**。
- 尺寸用 rem（border 除外）；不用 `text-color-brand`/`background-color-secondary` 等 CF 模板殘留；用 `-wrapper` 不用 `-wrap`；`padding-section-medium` 在這個站不存在。
- **專有名詞（人名、機構名、媒體名）逐字核對** —— `06_Webflow實作陷阱.md` 記載過一次人名用形近字、還先誤判成平台 bug。
- **發現明顯 bug 也要先問 Terris，不要自己改**（`00_` 6-8，含 2026-08-18 的 rollback 案例）。
- snapshot 過期或拿不到 computed style 時**標示驗證限制，不宣稱完成**。
