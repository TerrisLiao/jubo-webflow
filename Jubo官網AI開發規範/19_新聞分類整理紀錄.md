## 4. 追加：選擇分類後的切換動畫（同日）

Terris 回報「選擇分類按鈕之後沒有動畫」。實測線上頁面（Chromium、2026-10-01 06:23 發布版）：

- Webflow 樣式：`.cta-button.is-filter` 與 `.is-active` 都是 `--primary--accent` 實心，**選中與未選中顏色完全相同**；沒有 hover、沒有 transition。
- Slater：篩選按鈕的 `<label>` 沒有 `data-button-animate`，所以字元滾動動畫不會套用；`initNewsFilterDropdown()` 只處理 ≤991px 的下拉。
- Finsweet Attributes v2 篩選時會在 Collection List Wrapper 加 `is-list-filtering`，但站上**從未定義**這個 class 的樣式，所以文章是瞬間替換。
- 結論：不是本次分類整理或入口卡造成的回歸，是原本就沒有切換動畫。

已補上：

| Class | 屬性 |
|---|---|
| `news-content_list-wrap` | `transition: opacity 0.3s ease`（原本 base 為空） |
| `news-content_list-wrap.is-list-filtering`（新 combo） | `opacity: 0` |

Finsweet 會等 transition 結束才替換內容，移除 class 後再淡入。只動 opacity，不做位移（符合 `09` §6 減少動態原則）。
在線上頁面注入同樣 CSS 實測：點分類後約 0.3s 淡出 → 替換 → 0.3s 淡入，共約 0.7s。

> `news-content_list-wrap` 也用在 `/customer-success-stories`，但該頁沒有 Finsweet 篩選，transition 不會被觸發。

⏳ 待確認：選中按鈕與未選中按鈕仍是同色，若要讓「選了哪個」一眼看得出來，需要調整共用 combo `.cta-button.is-filter` 的未選中樣式（例如改成白色玻璃底＋teal 字），屬設計變更，等 Terris 決定。
