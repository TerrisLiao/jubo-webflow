## 2. 已執行的修改

### 2-1. Hero

```html
<div class="login-hub_hero-wrap">
  <Section Tag component  Text="系統登入">
  <h1 class="text-align-center login-hub_heading">
    選擇您的<span class="gradient-headline">照護系統</span>
  </h1>
</div>
```

- badge 換成 `Section Tag` component instance（component id `d7f8ec62-5aab-2d51-89d6-cbdddcf80ff7`），文案走 `Text` prop。
- `<h1>` 移除 `heading-style-h1`，改疊 `text-align-center`（weight 300、`text-wrap: balance`），字級交還 `h1` tag selector 的既有 RWD。
- 「照護系統」包 `.gradient-headline` span，與 `/`、`/company`、`/careers` 的 hero 標題寫法一致。

### 2-2. 三張卡片

卡片外層由 **Link Block 改成 Div Block**（class 不變，仍是 `.card-wrapper.is-login-hub`），因為 `CTA Button` component 的根元素本身是 `<a class="cta-button">`，放在 Link Block 裡會變成 `<a>` 巢狀 `<a>`，是無效 HTML。

```html
<div class="card-wrapper is-login-hub" data-login-system="karin|smc|icare">
  <div class="login-hub_card-insert">…玻璃層…</div>
  <div class="login-hub_card-visual">
    <img class="login-hub_card-image">        ← 掛真的 asset
    <div class="login-hub_image-wash"></div>
  </div>
  <div class="login-hub_icon-row">…svg…</div>
  <div class="login-hub_card-content"><h2 class="heading-style-h5 login-hub_card-title">…</h2></div>
  <div class="login-hub_card-action"><CTA Button /></div>
</div>
```

- 三顆按鈕改用 `CTA Button` component（component id `d130d393-247a-e6a4-a154-913119716033`），`data-button-animate` 等 Slater 需要的屬性由 component 自帶。
- 按鈕文案改成可獨立辨識：`登入住宿型系統` / `登入日照／居服系統` / `登入 i照護系統`（原本三顆都是「前往登入」）。
- `login-hub_card-action` 移除只為舊文字列存在的 `justify-content: space-between`、`color`、`font-weight`，剩 `display:flex` + `align-items:center`。卡片本身是 `justify-content: space-between` 的 flex column，按鈕自然靠底。

### 2-3. 影像

- **已驗證**：改後重讀元素樹與 Style Manager 確認 —— 三張卡各一個 `CTA Button` instance、三個 `Image` 都掛到 asset、頁面上 `Link` 元素數為 0（無巢狀 `<a>`）、login 相關 class 無孤兒。

## 5. 已知的工具限制（供後續 agent 參考）

- `data_element_tool > set_style` 與 `data_element_builder` 的 `set_style`，**遇到「同時存在 global 定義與 combo 定義」的 class 名稱會回報 `styles not found`**（例：`login-hub_heading` 同時有 `.login-hub_heading` 與 `.heading-style-h1.login-hub_heading`）。
- 可行的替代路徑：`data_whtml_builder` 傳 `<div class="a b">`，它能正確對應到既有 class（本次 hero、卡片外層、grid 都是這樣重建的）。既有元素要換 class，就用 whtml 新建一個、把子元素 `move_element` 過去、再刪掉舊的。
- `data_element_tool > set_attributes` 對「剛用 whtml 建好的元素」會回 MPS `[Conflict]`；改成在 whtml 的 HTML 字串裡直接寫屬性即可。
