## 4. 響應式間距變數（本站最重要的間距機制）

本站的 `padding-global`、`padding-section-*` 都是綁這組變數做 RWD，**不是**硬寫 rem。
需要做響應式間距時，優先綁這些變數。

| 尺寸 | Desktop | Tablet | Mobile |
|---|---|---|---|
| `xsmall` | 1rem｜16px | 0.75rem｜12px | 0.5rem｜8px |
| `small` | 1.5rem｜24px | 1rem｜16px | 0.75rem｜12px |
| `regular` | 2rem｜32px | 1.25rem｜20px | 1rem｜16px |
| `medium` | 4rem｜64px | 3rem｜48px | 2rem｜32px |
| `large` | 8rem｜128px | 5rem｜80px | 3rem｜48px |

CSS 變數名：
`--desktop-spacer--xsmall/small/regular/medium/large`
`--tablet-spacer--xsmall/small/regular/medium/large`
`--mobile-spacer--xsmall/small/regular/medium/large`

## 5. ⚠️ 重複／後來新增的變數（不要再用）

以下 9 個變數與既有主色重複，或是後續加頁時新增的一次性 token，**新工作一律改用第 1～4 節的正式變數**：

| 變數 | 值 | 問題 |
|---|---|---|
| `teal` | `#00b2c0` | 與 `primary/accent` 完全相同 |
| `jbc-teal` | `#00b2c0` | 與 `primary/accent` 完全相同 |
| `ink` | `#153339` | 與 `neutral/black` 功能重疊 |
| `jbc-ink` | `#1d2a31` | 同上 |
| `muted` | `#607579` | 與 `neutral/black-60` 功能重疊 |
| `jbc-muted` | `#67747d` | 同上 |
| `jbc-sky` | `#4ca7ed` | 未進入正式色票 |
| `jbc-violet` | `#a792ed` | 未進入正式色票 |
| `jbc-line` | `rgba(105,131,146,.15)` | 未進入正式色票 |

這 9 個沒有依 Client-First 的 `[元素] - [樣式] - [識別]` 語意命名法（正式變數用 `分類/名稱` 兩層），且用顏色本身當名字。
清理建議見 `07_合規稽核報告.md`。

## 6. 顏色使用速查

| 需求 | 用什麼 |
|---|---|
| 主標題文字 | `--neutral--black` |
| 內文 | `--neutral--black`（body 預設，通常不用加 class） |
| 次要說明文 | `--neutral--black-60` 或 `text-color-secondary` |
| 深底上的文字 | `--neutral--white` 或 `text-color-alternate` |
| CTA、強調、圖示 | `--primary--accent` `#00b2c0` |
| 深色區塊底 | `--primary--ocean` `#175e5e` |
| 淺灰區塊底 | `--neutral--bg-grey` `#f8f8f8` |
| Section Tag | Component `Section Tag`（已內建 `--primary--tag-text`） |

**絕對不要**手打 `#00b2c0` 這種色碼，一律綁變數。
