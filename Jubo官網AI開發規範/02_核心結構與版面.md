## 1. 標準頁面骨架

```html
<div class="page-wrapper">
  <div class="Global Style">            <!-- Component：Global Style（必要） -->
  <div class="Cookies">                 <!-- Component：Cookies -->
  <div class="Announce Bar">            <!-- Component（Landing Page 可移除） -->
  <div class="Navbar">                  <!-- Component（Landing Page 可移除） -->

  <main class="main-wrapper">
    <div class="all-sections-wrapper">  <!-- 本站慣用的 section 群組容器 -->

      <section class="section_[識別名]">
        <div class="padding-global padding-section-large">
          <div class="container-large">
            <!-- 內容 -->
          </div>
        </div>
      </section>

    </div>
  </main>

  <div class="Footer">                  <!-- Component（Landing Page 可移除） -->
</div>
```

> 本站在 `main-wrapper` 內另有 `all-sections-wrapper` 一層，屬專案擴充，沿用即可。
> `Page Gradient BG` Component 用於整頁漸層背景（33 個實例），大部分頁面都有。

## 2. Container 實際寬度

| Class | max-width | 換算 px | 用途 |
|---|---|---|---|
| `container-small` | 56rem | 896px | 純文字、表單、政策頁 |
| `container-medium` | 64rem | 1024px | 置中敘述、CTA 區 |
| `container-large` | 82rem | 1312px | **主要版寬**，絕大多數區塊用這個 |

> ⚠️ `container-large` 是 82rem，不是 CF 預設的 80rem。這是廠商為 Jubo 調整過的版寬，**不要改**。

三者共通：`width:100%` + `margin-left/right:auto`。

## 3. Section 上下 Padding（RWD）

> **讀回日期：2026-08-27**（四個斷點 `["main","medium","small","tiny"]` ＋ 變數值全部解析）
> 前一版這張表只記單一 class 的值，**在實務上是錯的**，原因見下方 3-2。

### 3-1. 實際生效的值（照鐵律 3 疊 `padding-global` 時）

**這張表才是你要看的。**

| Class | Desktop (main) | Tablet (medium) | Mobile L (small) | 備註 |
|---|---|---|---|---|
| `padding-section-small` | 4rem｜64px | **3rem**｜48px | 2rem｜32px | 標準小間距 |
| `padding-section-large` | 8rem｜128px | **5rem**｜80px | **3rem**｜48px | **預設值**，大多數區塊用這個 |
| `padding-section-xlarge` | 11rem｜176px | 8rem｜128px | — | 專案擴充（非 CF 原生） |
| `padding-section-full` | `height:95vh` flex 置中 | 20vh | 12vh | 專案擴充，用於滿版 Hero |

`tiny`（≤479px）四個都沒有額外覆寫。

### 3-2. ⚠️ 為什麼單一 class 的值不能拿來用

`padding-section-large` 同時存在**兩個** style：單一 global class，以及 `.padding-global.padding-section-large` combo。
combo 在 Tablet／Mobile 覆寫掉了單一 class 的值：

| 斷點 | 單一 `.padding-section-large` | combo `.padding-global.padding-section-large` | 實際生效 |
|---|---|---|---|
| main | 8rem（`desktop-spacer/large`） | 只有 `display:block; margin-top:0`，**沒有 padding** | 8rem |
| medium | 6rem（硬寫） | 5rem（`tablet-spacer/large`） | **5rem** |
| small | 4rem（硬寫） | 3rem（`mobile-spacer/large`） | **3rem** |

**鐵律 3 規定 `padding-global` 與 `padding-section-*` 必須疊在同一個 div** —— 所以站上**永遠**走 combo 那一欄。
單一 class 的 6rem／4rem 在實務中不會生效，照它排版會差 1rem。

同理 `padding-section-small`：單一 class 在 medium **沒有任何覆寫**，Tablet 的 3rem 完全來自 combo。

> **前一版的錯誤**：舊表把 `padding-section-small` 的 Tablet 記成 `1.25rem`。
> 四個斷點查完後**查無根據** —— 單一 class 沒有 medium 覆寫，combo 是 3rem。
> `1.25rem` 是 `tablet-spacer/regular` 的值，推測是當初誤植。

### 3-3. `padding-section-xlarge` 與 `-full` 只有 combo 形式

這兩個**沒有單一 global class**，站上只存在 `.padding-global.padding-section-xlarge` 與
`.padding-global.padding-section-full`。不疊 `padding-global` 就完全沒有效果。

### 3-4. 綁定的變數

| Class ／ 斷點 | 綁的變數 | 值 |
|---|---|---|
| `padding-section-large` main | `desktop-spacer/large` | 8rem |
| `padding-section-large` medium（combo） | `tablet-spacer/large` | 5rem |
| `padding-section-large` small（combo） | `mobile-spacer/large` | 3rem |
| `padding-section-small` main | `desktop-spacer/medium` | 4rem |
| `padding-section-small` medium（combo） | `tablet-spacer/medium` | 3rem |
| `padding-section-small` small（combo） | `mobile-spacer/medium` | 2rem |
| `padding-section-xlarge` medium（combo） | `desktop-spacer/large` | 8rem |

`padding-section-xlarge` 的 main（11rem）與 `padding-section-large` 的 medium／small 單一 class 值是**硬寫的**，沒綁變數。

> ⚠️ CF 標準的 `padding-section-medium` 本站**不存在**，不要使用。
> ⚠️ `padding-section-*` 必須與 `padding-global` 疊在同一個 div。

## 4. 左右 Padding（`padding-global`）

| 斷點 | 值 | 對應 Variable |
|---|---|---|
| Desktop | 4rem｜64px | `desktop-spacer/medium` |
| Tablet (medium) | 1rem｜16px | `tablet-spacer/small` |
| Mobile (small) | 0.75rem｜12px | `mobile-spacer/small` |

`padding-global` 全站只有這兩個屬性（`padding-left` / `padding-right`），**不要加任何其他 CSS**。

## 6. `section_` 命名現況

本站有 **63 個** section class，命名慣例是 `section_[頁面或區塊識別名]`，例如：

`section_hero` `section_home-about` `section_home-solutions` `section_home-news`
`section_product-hero#1`~`#5` `section_product-features` `section_product-prices` `section_product-intro`
`section_solutions-basic-model` `section_solutions-bento` `section_solutions-why-us` `section_solutions-brand`
`section_customer-story` `section_hero-customer-story` `section_cases-slider` `section_testimonial_cards`
`section_news-content` `section_news-grid` `section_related-news` `section_home-news`
`section_cta` `section_cta-process` `section_faq` `section_contact-form` `section_platform-form`
`section_footer` `section_nav` `section_announce-bar` `section_page-header` `section_popup`
`section_about` `section_culture` `section_manifesto` `section_internship` `section_location`
`section_404` `section_privacy-terms` `section_big-text` `section_tag` `section_tab`
`section_client-logo` `section_client-meeting-event` `section_share-event` `section_sales`
`section_manual` `section_long-term-resource` `section_IoT-filter` `section_2col-sticky`
`section_company-hero` `section_product-big-numbers` `section_product-cases` `section_product-scroll-card`
`section_product-switcher` `section_jubo-ai_cards` `section_home-care-banner` `section_hero-solutions`

**新增 section 時**：先看有沒有語意相符的既有 section class 可用，沒有才新建 `section_[新識別名]`。

（用了連字號 `section-`，這是 CF v1 的舊寫法）

⚠️ 以下 5 個 class 名稱含 `#`，是不合法字元，**不要再新增這種寫法**：
`section_product-hero#1` ~ `section_product-hero#5`

## 7. 排版（Typography）實際值

`body` 預設：字型 **Poppins**，`font-size: 1.125rem`（18px），`line-height: 150%`，
色 `--neutral--black` `#151717`，背景 `--neutral--bg-grey` `#f8f8f8`

> **⚠️ 標題字級有三層，值都不一樣。動手前先確認你要改哪一層。**
> 讀回日期：2026-08-27（四個斷點）

### 7-1. Tag selector（`h1` / `h2` / `h3`）— 沒加任何 class 時的預設

**鐵律 5：tag selector 屬於全站共用資產，未經明確指示不得修改。**

| Tag | main | medium | small | tiny | line-height / weight |
|---|---|---|---|---|---|
| `h1` | 5rem | 3.75rem | 3.5rem | **10vw** | 120% / 300 |
| `h2` | 3.8rem | 3rem | 2.75rem | 2rem | 120% / 300 |
| `h3` | 2rem | — | — | 1.5rem | 120% / 400 |

`h1` 與 `h3` 的顏色綁 `--neutral--black`；`h1` 明確指定 `font-family: Poppins`。

### 7-2. Utility class（`heading-style-h*`）— 疊上去才會生效

| Class | main | medium | small | line-height | weight |
|---|---|---|---|---|---|
| `heading-style-h1` | 4rem｜64px | — | **2.5rem** | 1.1 | 700 |
| `heading-style-h2` | 3rem｜48px | — | **2rem** | 1.2 | 700 |
| `heading-style-h3` | 2rem｜32px | **1.75rem** | **1.5rem** | 1.5 | **500** |
| `heading-style-h4` | 1.5rem｜24px | — | — | 1.4 | 700 |
| `heading-style-h5` | 1.25rem｜20px | — | — | 1.5 | 700 |
| `heading-style-h6` | 1rem｜16px | — | — | 1.5 | 700 |

> 粗體的響應式覆寫是 2026-08-27 才補上的 —— **前一版只記了 main，漏掉全部覆寫**。
> h4/h5/h6 的斷點覆寫尚未逐一讀回，標示為「—」代表未確認、不是確認沒有。

### 7-3. `.richtext h1` / `h2` / `h3` — CMS 內文用的第三層

**寫 `/news` 文章、CMS rich text 內容時，套到的是這一層，不是 7-1 的 tag 預設。**

| Selector | main | medium | small | line-height / weight |
|---|---|---|---|---|
| `.richtext h1` | 3rem | 2.75rem | 2.5rem | 100% / 400 |
| `.richtext h2` | 2.5rem | 2.25rem | 2rem | 100% / 400 |
| `.richtext h3` | 2.25rem | 2rem | 1.75rem | 100% / 400 |

`.richtext h1` 另有 `margin-bottom: 1.25rem`；`h2` / `h3` 另有 `margin-top: 2rem; margin-bottom: 1.25rem`。

> 🚫 **`.richtext` 在 Slater 鎖定清單裡**（見 [`../custom-code/slater-selectors.md`](../custom-code/slater-selectors.md)），**不可改名**。
> 寫文章前也請看 [`12_AEO文章寫作指南.md`](12_AEO文章寫作指南.md)。

| Class | font-size |
|---|---|
| `text-size-large` | 1.5rem｜24px |
| `text-size-medium` | 1.25rem｜20px |
| `text-size-regular` | 繼承 body（1.125rem） |
| `text-size-small` | 0.875rem｜14px |
| `text-size-tiny` | 1rem｜16px（line-height 145%） |
| `text-size-xsmall` | 0.75rem｜12px（專案擴充，非 CF 原生） |

> ⚠️ `text-size-tiny`（1rem）比 `text-size-small`（0.875rem）**還大**，這是本站的既有狀態，使用時要注意實際大小而不是名稱直覺。

字重：`text-weight-normal` 400 ／ `text-weight-medium` 500（專案擴充）／ `text-weight-semibold` 600
⚠️ CF 標準的 `text-weight-light`、`text-weight-bold`、`text-weight-xbold` 本站**不存在**。
