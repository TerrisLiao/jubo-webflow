# 18 無障礙稽核與 90% 達標計畫

稽核日期：2026-09-15
稽核範圍：`jubo-health.com` sitemap 全部 **156 個 URL**（含 `/jp/overview`、`/jp/about-us`、6 個 demo 頁）
起因：Webflow AEO 報告回饋「**無障礙覆蓋率 65%，需推到 90%+**，這是 Technical 支柱從 Level 3 升到 Level 4 的門檻」

## 這份文件在幹什麼

`11_AEO稽核與優化計畫.md` 已經涵蓋 AEO 的四支柱，其中 P1（語意結構）與 P2-G（圖片 alt）跟無障礙重疊。

兩份的關係：

| | `11_AEO稽核與優化計畫.md` | 本文件 |

## 稽核方法（可重現）

1. `curl` 抓 sitemap 的 156 個 URL，**全部 HTTP 200**，存成靜態 HTML 快照
2. 用 cheerio 對 156 頁逐頁解析結構指標（alt、label、landmark、heading、link name、duplicate id…）
3. 用 **axe-core 4.13.0（@axe-core/playwright）＋ Chromium 141 headless、1440×1000、locale zh-TW** 跑 16 個代表性模板頁，
   規則集 `wcag2a wcag2aa wcag21a wcag21aa wcag22aa best-practice`
4. 抓線上 CSS（`jubo-health.webflow.shared.c5b1f2440.min.css`）與 Slater 的 `60294.css` / `60292.js` 做全文檢查
5. 在瀏覽器裡實際 focus 前 30 個可聚焦元素，讀 computed style 驗證焦點框

工具與腳本放在 [`../custom-code/a11y-audit/`](../custom-code/a11y-audit/)，可原樣重跑做前後對照。

### 驗證限制（務必標示，不要當成完整結論）

- axe-core 只跑了 **16 個模板頁**，不是 156 頁。其餘 140 頁的對比與 landmark 數字是**由同模板推得**，不是實測。
- **對比度有 838 個節點 axe 判為 `incomplete`**（漸層背景無法判定、`data-button-animate-chars` 把字拆成單字元導致「內容太短無法判定」）。

- 本文件的分數是 **Jubo 自建模型**，不是 Webflow 報告那個 65%（見下一節）。

| 情境 | 上限 | 90% 門檻 |

   現在少了對比那 7 分，它變成跨過 90% 的必要條件。**要提早排人。**

如果 90% 是硬性交付目標，實務上只有兩條路：
**(a)** 接受 87.7%／93.0%，並向 Webflow 說明對比項是刻意保留的設計決策；或
**(b)** 只為對比開一個最小例外（見改寫後的 B1 末段）。

## 一句話結論

**問題不在「有很多頁要修」，在「有幾個共用元件錯了，然後被複製到每一頁」。**

全站 156 頁裡，**壞掉的幾乎是同一組東西**：Navbar 的 logo 與漢堡鈕、Footer 的 logo、Cookie 橫幅的關閉鈕、
`main-wrapper` 的 tag、品牌主色的對比度。這五件事修好，全站每一頁同時變好。

具體到「Webflow 報告點名的三件事」：

| 報告點名 | 實測結論 |
|---|---|
| **alt text** | 比想像中好。1,196 張空 alt 裡 246 張**本來就該是空的**、631 張旁邊已有同義文字，**真正要補的是 319 張**，集中在 21 個版位 |
| **form labels** | 比想像中糟。全站 477 個表單欄位裡只有 7 個沒 label——但那 7 個**就是 `/contact` 的主要名單表單**，而且焦點框被拿掉、沒有 autocomplete、送出結果沒有 aria-live |
| **semantic HTML** | 最嚴重。156 頁裡 **150 頁的 `main-wrapper` 是 `<div>`**、**0 頁有跳至主內容連結**、**294 個 logo 連結完全沒有無障礙名稱** |

另外兩件報告沒點名、但實測分數更低的：**全站沒有任何 `prefers-reduced-motion` 處理**（本 repo `09_GSAP動畫與互動規範.md` §6 已明文要求，屬規範與實作脫鉤），
以及**品牌主色 `#00b2c0` 當文字色時對比只有 2.58:1**，AA 要 4.5:1。

## 計分模型：為什麼這裡不是 65%

Webflow 報告的 65% 用的是他們自己的評分表，**我們沒有那張表，無法重現**。
為了讓「65 → 90」這件事可以被驗收，這裡建一套自己的、可重跑的模型，叫 **JA11Y-23**：

- 23 條判準，每條對應一個 WCAG 成功準則（或 axe best-practice）
- 依嚴重度給權重 1–4，單頁滿分 57
- 在 **axe 實測過的 16 頁**上逐頁計分，取平均

**基準分：40.9%**（2026-09-15）

比 Webflow 的 65% 低很多，因為這個模型只要單頁有一個 A 級失敗就整條判 0，沒有部分給分。
**不要拿這兩個數字互相換算。** 追蹤時只看 JA11Y-23 自己的前後差，Webflow 的 90% 門檻另外用他們的報告驗收。

好消息是兩邊指向同一批修正項，所以做完下面的 A→C 三組，兩個分數會同時過門檻。

# A 組 ── 共用元件層（做這一組，全站 156 頁同時變好）

> ⚠️ **全部落在 Component Definition，依 `00_AI工作守則.md` 鐵律 5 必須先取得 Terris 明確授權才能動。**
> 好消息是這五項**都只加屬性、不改 class 名、不改任何 CSS 值**，
> 所以 `custom-code/slater-selectors.md` 的禁令不受影響（見「與既有規範的衝突」一節）。

## A1. Logo 連結完全沒有無障礙名稱（全站 294 個）

`Navbar` 與 `Footer` 的 logo 都是這個結構：

```html
<a href="/" class="logo-link w-inline-block">
  <div class="logo-svg w-embed">
    <svg ... aria-hidden="true" role="img">   <!-- ← 整個 logo 對輔助科技隱形 -->
```

SVG 標了 `aria-hidden="true"`，連結裡又沒有任何文字，所以**這個連結的無障礙名稱是空字串**。
螢幕閱讀器使用者聽到的是「連結」兩個字，不知道它去哪。每頁 2 個（header + footer）× 147 頁 = **294 個**。

沒有這個問題的 9 頁：6 個 demo 頁與 2 個 `/jp` 頁沒有 Navbar／Footer；
`/ecosystem/jubo-digital` 用的是另一組 `Jubo-Digital-Navbar` / `Jubo-Digital-Footer`，
它的 logo 是 `<img alt="Jubodigital品牌標誌，含英文 Jubo Digital 及中文智齡數位科技字樣。">` —— **這組做對了，可以直接當範本**。

**修法**：在 `.logo-link` 與 `.logo-link.is-footer` 上加 `aria-label="Jubo 智齡科技 首頁"`。
SVG 的 `aria-hidden="true"` **保留不動**（那是正確的，名稱由連結自己提供）。

| 影響 | axe `link-name` 32 個節點 → 2 個；JA11Y 判準 2.4.4 由 1/16 → 15/16 |
|---|---|
| 成本 | 極低（2 個元素） |
| 風險 | 零（不動 class、不動 CSS） |

## A2. 手機漢堡鈕是一個空的 `<a href="#">`（全站 147 個）

```html
<a href="#" class="mobile-menu-icon_wrap w-inline-block">   <!-- 無文字、無 aria-label、無 role、無 aria-expanded -->
```

這是全站唯一的「完全空連結」，而且它是**手機版唯一的導覽入口**。
鍵盤使用者 Tab 到它會聽到「連結」，按下去畫面有變化但沒有任何宣告。

**修法**：
- 加 `aria-label="開啟主選單"`
- 加 `aria-expanded="false"`、`aria-controls="mobile-menu"`（`.mobile-menu_wrap` 加對應 `id`）
- Slater JS 開關選單時同步切 `aria-expanded`

⚠️ `.mobile-menu-icon_wrap`、`.mobile-menu_wrap`、`.mobile-menu-is-open` **都在 Slater 鎖定清單內**。
加屬性安全；**改名會壞掉**。`aria-expanded` 的同步要改 Slater 的 `60292.js`，
那是站台背景設施，依 `slater-selectors.md` 的立場需要另外走流程 —— **這一小段請 Terris 決定要不要動**。
若決定不動 Slater，至少先把 `aria-label` 補上（純 Webflow 可完成，解掉「空連結」這一半）。

## A3. Mega Menu 的三個觸發器不宣告展開狀態（全站 441 個）

```html
<a href="#" class="nav-link is-solutions w-inline-block">找到適合你的方案</a>
<a href="#" class="nav-link is-products w-inline-block">產品</a>
<a href="#" class="nav-link is-resources w-inline-block">資源</a>
```

有可見文字（所以不算 A1 那種空連結），但：
- 用 `<a href="#">` 扮演「展開選單」的按鈕 —— 語意錯了，螢幕閱讀器會說「連結」
- 沒有 `aria-expanded` / `aria-haspopup` / `aria-controls`
- **全站 `aria-expanded` 總共只出現 3 次**（156 頁），等於完全沒用

> **2026-09-15 決策：不動 Slater。** 以下是改寫後、不需要編輯 `60292.js` 的做法。
> 另見決策紀錄——**這一項現在是 90% 的必要條件，不能跳過。**

**修法**：

1. **（Designer，純屬性）** 三個觸發器加 `role="button"` + `aria-haspopup="true"` + `aria-controls`；
   `.mega-menu_wrapper` 加對應 `id` 與 `aria-label`
2. **（Webflow Site Settings → Footer Code，一支新的小 script）**
   用 `MutationObserver` 盯 `.mega-menu_wrapper` 的 `.mm-is-open` class，
   變動時把對應觸發器的 `aria-expanded` 切成 `true`／`false`，並補 Esc 關閉

第 2 步**不是修改 Slater**，是在 Webflow 自己的 custom code 區另外加一支只做無障礙的 script，
Slater 的 `60292.js` 一個字都不動。代價是多一個腳本依賴，且它讀 `.mm-is-open` 這個 Slater class
—— 所以 `.mm-is-open` 之後同樣不可改名（本來就在鎖定清單裡）。

> 🚫 **不要用「加一個永遠是 `false` 的靜態 `aria-expanded`」來充數。**
> 那會讓 JA11Y-23 的判準通過，但對螢幕閱讀器使用者是**謊報**——選單明明開著卻說沒開，
> 比完全不宣告更糟。**這是刷分數，不是修無障礙。**

⚠️ `.nav-link`、`.mega-menu_wrapper`、`.mega-menu_inner-wrapper`、`.mm-is-open` 皆為 Slater 鎖定，只加屬性、不改名。

## A4. Cookie 橫幅的關閉鈕沒有名稱（全站 150 個，axe serious）

```html
<div fs-cc="close" class="fs-cc-banner_close" role="button" tabindex="0"></div>
```

宣告了 `role="button"` 卻沒有任何名稱 —— axe 規則 `aria-command-name`，**16/16 頁全中**。
這個橫幅在 H1 之前、每頁都出現，是螢幕閱讀器使用者遇到的第一個互動元素。

**修法**：加 `aria-label="關閉 Cookie 通知"`。屬於 `Cookies` component（Finsweet Cookie Consent）。

## A5. `main-wrapper` 有 150 頁是 `<div>`，全站 0 個跳至主內容連結

實測：

| 項目 | 156 頁實況 |
|---|---|
| 有 `<main>` | **6 頁**（`/login`、`/jp/about-us`、`/jp/overview`、3 個 news landing 頁） |
| 有 `role="main"` | **0 頁** |
| `main-wrapper` 的 tag 是 `main` | **6 頁**，其餘 150 頁是 `div` |
| 有「跳至主內容」連結 | **0 頁** |
| axe `region`（內容在 landmark 外） | 16/16 頁，**738 個節點** |

> ✅ **這是回歸規範，不是違反規範。**
> `02_核心結構與版面.md` L9-32 寫的標準骨架**本來就是 `<main class="main-wrapper">`**。
> 而且站上已有 **6 頁做對了**（`/login` 與兩個 `/jp` 頁），做法有現成前例可抄。

**修法**：
1. 把每頁的 `.main-wrapper` 的 tag 從 `div` 改成 `main`
2. `Navbar` 最前面放一個「跳至主內容」連結，`href="#main"`，用 CF 的視覺隱藏手法（focus 時顯示）
3. `.main-wrapper` 加 `id="main"`

這一項單獨就把 axe 的 738 個 `region` 節點清掉，是全站投報比最高的單一動作。

## B1. 品牌主色當文字色只有 2.58:1

| 前景 | 背景 | 對比 | 用在哪 | AA 門檻 |

```css
select:focus-visible,
textarea:focus-visible,

  outline: 0.125rem solid var(--primary--accent-text);   /* B1 新增的深色版 */
  outline-offset: 0.125rem;
}
```

## B3. 全站沒有任何 `prefers-reduced-motion` 處理

實測：`jubo-health.webflow.shared.*.min.css`、`slater.app/20018/60294.css`、`slater.app/20018/60292.js`

**修法**：分兩層，Webflow 那層可以先做、不用等 Slater：

1. `Global Style` embed 加全域兜底：

   ```css
     *, *::before, *::after {
       animation-duration: 0.01ms !important;
       animation-iteration-count: 1 !important;
       transition-duration: 0.01ms !important;
       scroll-behavior: auto !important;
     }
   }
   ```
   這同時也處理掉 `.section_announce-bar` 那個 6 秒無限循環的漸層動畫。
2. Slater `60292.js` 依 `09` §6 的寫法包 `gsap.matchMedia()` —— 需要 Terris 決定是否動 Slater。


|---|---|---|
| 只有 `placeholder`，沒有 `<label>` | 1.3.1 A / 3.3.2 A | placeholder 一開始打字就消失；部分螢幕閱讀器根本不朗讀它 |

2. 依序補 `autocomplete`：`family-name` / `given-name` / `organization` / `organization-title` / `email` / `tel` / `off`
3. `.w-form-done` 加 `role="status"`（隱含 `aria-live="polite"`）、`.w-form-fail` 加 `role="alert"`

## E3. alt 怎麼寫（給執行的人）

- 描述**這張圖在這個位置要傳達什麼**，不是描述畫面上有什麼
- 海報類：把圖上的關鍵資訊寫進去（`2026 客戶見面會秋季場，10/24 台北，主講：…`）
- UI 截圖：寫它在示範什麼功能（`住宿型照護系統的班表管理畫面，顯示一週排班與人力配置`），不要寫「系統截圖」
- 客戶 logo：寫機構全名
- **不要**以 `圖片`、`照片`、`image`、`未命名設計 (36)` 開頭（實測全站目前只有 4 張是這種無意義 alt，維持住）
- 純裝飾就留 `alt=""`，**不要為了補而補**

# 不建議做的事（避免日後重複提案）

| 提案 | 為什麼不做 |
|---|---|
| 把 1,196 張空 alt 全部補上文字 | 其中 877 張（DECORATIVE + REDUNDANT）補了反而讓螢幕閱讀器重複朗讀，是**退步**。只補 319 張 |
| 為了無障礙去改 Slater 鎖定的 class 名 | `slater-selectors.md` 的禁令不變。本計畫**全部的修法都只加屬性、不改名** |
| 直接改 `--primary--accent` 的值把對比拉高 | 那是改設計，違反 `00` §6-8。正確做法是**新增**一個文字專用深色變數（B1） |
| 用 HTML Embed 蓋一層無障礙修補 | 違反鐵律 4。焦點框與 reduced-motion 應該加在**既有的 `Global Style` component** 裡，那是 Client-First 官方的全域 CSS 位置 |
| 為了 `region` 把每個 CMS 卡片包一層 `role="region"` | landmark 太多等於沒有 landmark。正解是 A5 的 `<main>` + D2 的 `<article>` / `<aside>` |
| 追著 Webflow 那個 65% 做逐點換算 | 我們沒有他們的評分表。用 JA11Y-23 追自己的前後差，門檻驗收另外看他們的報告 |
| 加一個永遠是 `false` 的靜態 `aria-expanded` 來讓判準過關 | 判準會過，但對螢幕閱讀器是**謊報**——選單開著卻說沒開，比不宣告更糟。這是刷分數不是修無障礙（見 A3） |
| 為了 `/jp` 兩頁的 `lang` 去改站台級語言設定 | 會把其餘 154 頁中文頁一起錯標成日文。只在那兩頁的最外層 wrapper 加 `lang="ja"`（見 D3） |
| 為了補對比而放大字級或加粗 | 2.58:1 就算套用大型文字門檻（3:1）仍然不夠。對比比值與字級字重無關 |
