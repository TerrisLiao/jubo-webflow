## 1. 最高優先：先設計頁面，再選元件

**既有頁面與元件是設計材料，不是頁面策略。**

> 🚫 禁止複製 Company／Product／Solution 整頁後只換文字，然後宣稱完成 Landing Page。

動手前必須先定義這七項：

1. 目標受眾
2. **單一**轉換目標
3. 核心價值主張
4. 訪客疑慮與阻力
5. 信任證據
6. Section Flow
7. Primary CTA 與 Secondary CTA

**七項齊備、Section Flow 與元件對照表交給 Terris 確認之後**，才開始選 Hero / Cards / Stats / Tabs / CTA 等既有模組。
不同頁面依目的重新組合，**不得預設沿用來源頁的 Section 順序**。

> 這條與 `13_外部AI資源評估與採用紀錄.md` 抽取的 *preview-then-execute* 是同一件事：
> 先給看得懂的預覽、確認後才動 Designer。

## 2. 設計權威分層

### Tier A — 核心系統，優先使用

改動會影響全站，但**使用**它們永遠是對的。

| 類別 | 項目 |
|---|---|
| Variables | `Jubo Variables`（見 [`04_設計變數與色彩.md`](04_設計變數與色彩.md)） |
| Tag styles | Body、`h1`–`h6` |
| 結構 utility | `padding-global`、`padding-section-*`、`container-small` / `-medium` / `-large` |
| 常用 wrapper | `section-header_wrapper`、`section_tag` |
| 按鈕 | `cta-button`、`glass-button`、`glass-element`、`glass-effect*` |
| 版面 | `_2col-grid`、`_3col-grid`、`_4col-grid` |
| 視覺 | `img-mask`、`gradient-bg`、`home-gradient-bg` |
| Component | `Navbar`、`Footer`、`CTA Section #1`、`Page Gradient BG`（ID 見 [`05_元件清單.md`](05_元件清單.md)） |

### Tier B — 正式功能模式，依頁面目的使用

| 項目 |
|---|
| `hero_component` |
| `product-hero_component`（含 `product-hero_center-wrap`、`product-hero_twoside-wrap` 變體） |
| `stats_grid`、`single-stats_wrapper` |
| `product-scroll-card_*` |
| `tab_*` |
| `news-card_*` |
| `testimonial_cards_*` |
| `jubo-ai_cards_*` |

> ⚠️ **`product-hero#1`〜`#5`、`header#1_*` 這類帶 `#` 版本號的 class 不是 Tier B。**
> 它們是歷次複製 Hero 區塊留下的分身，不要沿用也不要模仿 —— 一律改用乾淨的 `product-hero_component`。
> 完整清單見 [`07_合規稽核報告.md`](07_合規稽核報告.md) 第五節。

### Tier C — Prototype／頁面專屬，不得自動當標準

`jbc-*`、`jpj-*`、`why-us-*` 這幾組。

只有以下三種情況才能用：

1. Terris 明確指定
2. 該模組已經正式核准
3. 明確以該 prototype 作為參考

**不得用 Tier C 的 token 取代正式 Variables。**

## 3. Hero 選擇

| 類型 | 適用 | 做法 |
|---|---|---|
| **Centered Brand Hero** | 品牌、願景、公司理念、AI 概念 | `hero_component` ＋ `container-small` ＋ 大型主視覺 ＋ `Page Gradient BG` |
| **Product Two-column Hero** | 產品與解決方案 | `product-hero_component`，Desktop 約 `.85fr 1fr`，Tablet 改單欄 |
| **Lead-generation／Partnership Hero** | Demo、活動、合作夥伴、市場 Landing Page | 清楚受眾 ＋ 結果導向 H1 ＋ 短說明 ＋ **單一**主 CTA ＋ 靠近首屏的信任證據 |

**禁止**：

- 因為來源頁用 Centered Hero 就照搬
- 假產品 UI、抽象 AI 圖
- 首屏放完整公司歷史
- 多個同級 CTA

## 4. Landing Page 選擇矩陣

| 頁面類型 | Section Flow |
|---|---|
| 品牌頁 | 主張 → 信念 → 實績 → 團隊／故事 → CTA |
| 產品頁 | 痛點 → 產品結果 → 工作流程 → 功能 → 案例 → CTA |
| 解決方案頁 | 角色痛點 → Before/After → 解法架構 → 服務體系 → CTA |
| 合作夥伴頁 | 市場課題 → 雙方角色 → 合作價值 → 執行方式 → 信任 → CTA |
| 活動頁 | 活動價值 → 適合誰 → 議程 → 講者／證據 → 報名 |
| **日本市場頁** | 日本現場課題 → Jubo × 在地夥伴角色 → 解決方案 → 導入方式 → 台灣實績與安全 → FAQ → CTA |

> ⚠️ **日本市場頁不可把 Company Page 當主要骨架。**
> 首屏先回答「對日本現場的價值」，公司歷史與台灣實績只作為**信任證據**放後面。
> 實際頁面現況見 [`../JP日本市場頁面改版/README.md`](../JP日本市場頁面改版/README.md)。

## 5. 影像來源優先序

由高到低：

1. Webflow 已核准的 Assets
2. 真實 Jubo 團隊／客戶／產品素材
3. 已核准的 UI／設備照
4. 經審核的新圖

### 技術規則

| 項目 | 值 |
|---|---|
| Photography | `object-fit: cover` |
| UI／Illustration | `object-fit: contain` |
| 常見比例 | 16:9｜人物 1:1｜Hero 2:1 或約 2.39:1 |
| Radius | Desktop 約 2rem｜Tablet 1.25rem｜Mobile 1rem |

### 🚫 禁止

- 生成假的 Jubo UI、設備、客戶 Logo、認證、不合理的照護場景
- **拿 Figma 的 wireframe／佔位文字（例如「內容內容內容」）當最終視覺**
  → 要用產品介面截圖，優先取自實際 Figma 完稿或已上線畫面；不確定是不是完稿就先問
- 圖片沒有 alt text（裝飾圖要正確標示為裝飾）

### 2026-08-27 class 名稱驗證結果

以 `data_style_tool > query_styles` 逐項讀回，**Tier A 與 Tier B 列出的 class 全部存在**：

- **Tier A**：`section-header_wrapper`、`section_tag`、`cta-button`、`cta-button_bg`、`glass-element`、
  `glass-effect` ＋ 7 個 `glass-effect__*`、`img-mask`、`gradient-bg`、`home-gradient-bg`、
  `2col-grid` / `3col-grid` / `4col-grid`
- **Tier B**：`hero_component`、`product-hero_component`、`product-hero_center-wrap`、
  `product-hero_twoside-wrap`、`stats_grid`、`single-stats_wrapper`、`product-scroll-card_*`（8 個）、
  `tab_component`、`news-card_*`、`testimonial_cards_*`、`jubo-ai_cards_*`

**一個命名細節**：`2col-grid` / `3col-grid` / `4col-grid` 在 Designer 裡的 **name 沒有前導底線**，
CSS selector 才是 `._2col-grid`（Webflow 對數字開頭的 class 自動補底線）。
用 MCP 查 style 時要用 `2col-grid`，寫 CSS 選擇器時才是 `._2col-grid`。

**Tier B 警告已證實**：`section_product-hero#3`、`product-hero#3_component`、`product-hero#4_gallery`、
`section_product-hero#5` 等分身確實存在於站上，且數量不少。**一律改用 `product-hero_component`。**
