# 03｜全域工具類（Utility Class）完整清單

Utility class = 只用連字號、不含底線、全站共用的 class。
**改動任何一個 utility class 的 CSS，會影響全站 30+ 個頁面。未經明確指示不得修改。**

---

## A 區｜Client-First 官方 Utility（130 個・可安心使用）

這些是廠商建站時從 Client-First 帶入的標準工具類，命名與行為都符合規範。

### 核心結構
`page-wrapper` `main-wrapper` `padding-global` `container-small` `container-medium` `container-large` `padding-section-small` `padding-section-large`
> `padding-section-medium` 本站不存在。

### 標題樣式
`heading-style-h1` `heading-style-h2` `heading-style-h3` `heading-style-h4` `heading-style-h5` `heading-style-h6`
> 只在「要覆蓋 H 標籤預設樣式」時才加。H1 就該長得像 H1 的話，不要加 class。

### 文字大小
`text-size-tiny` `text-size-small` `text-size-regular` `text-size-medium` `text-size-large`

### 文字樣式
`text-style-allcaps` `text-style-italic` `text-style-link` `text-style-muted` `text-style-nowrap` `text-style-quote` `text-style-strikethrough` `text-style-2lines` `text-style-3lines`

### 文字對齊

### 文字顏色
`text-color-primary`（#111）　`text-color-secondary`（#4c4c4c）　`text-color-alternate`（white）
> ⚠️ `text-color-brand`、`text-color-brand-dark` 是範本殘留的綠色，**不要用**（見 07 稽核報告）。

### 字重
`text-weight-normal`（400）　`text-weight-semibold`（600）
> `text-weight-medium`（500）為專案擴充，見 B 區。

### 間距方向（需搭配尺寸 class）
`margin-top` `margin-bottom` `margin-left` `margin-right` `margin-horizontal` `margin-vertical`
`padding-top` `padding-bottom` `padding-left` `padding-right` `padding-horizontal` `padding-vertical`

| Class 後綴 | 值 | px |

| `-0` | 0rem | 0 |
| `-tiny` | 0.125rem | 2 |

適用於 `margin-*`、`padding-*`。標準寫法是**兩個 class 一組**：
`margin-bottom margin-small`、`padding-vertical padding-large`

### Spacer 空白區塊（單一 class，上 padding）
`spacer-tiny`(0.125rem) `spacer-xxsmall`(0.25rem) `spacer-xsmall`(0.5rem) `spacer-small`(1rem) `spacer-medium`(2rem) `spacer-large`(3rem) `spacer-xxlarge`(5rem) `spacer-huge`(6rem) `spacer-xhuge`(8rem) `spacer-xxhuge`(12rem)
> `spacer-xlarge` 本站不存在。

### 最大寬度（實際值）

| Class | max-width | px |
|---|---|---|
| `max-width-xxsmall` | 12rem | 192 |
| `max-width-xsmall` | 16rem | 256 |
| `max-width-small` | 28rem | 448 |

| `max-width-large` | 48rem | 768 |
| `max-width-xlarge` | 64rem | 1024 |
| `max-width-xxlarge` | 80rem | 1280 |
| `max-width-full` | none | — |

響應式取消：`max-width-full-tablet` `max-width-full-mobile-landscape` `max-width-full-mobile-portrait`

### 隱藏
`hide-tablet` `hide-mobile-landscape` `hide-mobile-portrait`
> ⚠️ CF 標準的 `hide` 在本站 Style Manager 中僅以 combo 形式出現（`._2col-grid.hide` 等）。要隱藏元素時優先用上述三個具體斷點 class。
> ⚠️ 站上另有 `hide-mobile`，非標準，見 B 區。

### 背景色
`background-color-primary`（#111）　`background-color-alternate`（white）
> ⚠️ `background-color-secondary`（螢光黃綠）、`background-color-tertiary`（#6e30f7 紫）是範本殘留，**不要用**。

### 圖示尺寸
`icon-height-small`(1rem) `icon-height-medium`(2rem) `icon-height-large`(3rem)
`icon-1x1-small`(1rem) `icon-1x1-medium`(1.5rem) `icon-1x1-large`(2.5rem)

### 比例
`aspect-ratio-square` `aspect-ratio-portrait` `aspect-ratio-landscape` `aspect-ratio-widescreen`

### 溢出
`overflow-visible` `overflow-hidden` `overflow-scroll` `overflow-auto`

### 定位與互動
`align-center`（margin 置中）　`layer`（絕對定位滿版）　`z-index-1` `z-index-2`
`pointer-events-none` `pointer-events-auto`　`inherit-color`　`display-inlineflex`　`spacing-clean`

### 按鈕
`button`（基底，變體用 `is-` combo）

## C 區｜不合規・不要沿用

見 `07_合規稽核報告.md` 的完整清單與處理建議。這裡只列 AI 最容易誤用的：

| 不要用 | 改用 |
|---|---|
| `page-wrap` / `main-wrap` | `page-wrapper` / `main-wrapper` |
| `hide-mobile` | `hide-mobile-landscape` / `hide-mobile-portrait` |
| `text-color-brand` / `text-color-brand-dark` | `text-color-primary` 或 Variables `--primary--accent` |
| `background-color-secondary` / `background-color-tertiary` | Variables `--primary--accent` 等 |
| `css-tootlip__tip`（錯字） | `css-tooltip_*` |
| `Heading` / `Paragraph` / `Image` / `Link` / `List` / `Svg` / `Code Embed` 等 Webflow 預設名 | 一律改成語意化 `folder_element` |
| `jbc-v3-*` / `jp3-*` / `jp6-*` / `jp7-*` / `jp8-*` 等扁平連字號自訂 class | 改成 `folder_element`，變體加 `is-` |

> ⚠️ **改名之前先查 [`custom-code/slater-selectors.md`](../custom-code/slater-selectors.md)。**
> 這張表叫你「改用」的前提是該 class 沒有被 Slater 外部 CSS/JS 引用。
> 被引用的（例如 `.cascading-slider__*`、`.category-tag`、`.cta-button`）**一律不可改名**，只能維持現狀並註記。
