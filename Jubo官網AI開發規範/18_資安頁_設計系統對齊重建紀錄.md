### ⚠️ ISO／HIPAA 標章：目前是「文字版」，不是真標章

掃過站上全部 **495 個 asset**，**沒有任何 ISO 或 HIPAA 的認證標章圖檔**
（唯一名稱接近的 `jp-security-compliance.webp` 是插圖，不是標章）。

因此 v3 的認證列做法是：**沿用日本頁的 inline SVG icon ＋ 標準名稱文字**，
以 `--neutral--black-60` 呈現灰階，四項並排、靜態不輪播。

→ **待 Terris 提供驗證機構核發的正式標章檔**，版位已留好，換圖即可。

## 3-2. v4 認證標章改用授權原檔（2026-09-21 第三輪）

v3 的認證列是「inline SVG icon ＋ 標準名稱文字」的暫代版，因為當時站上沒有任何標章圖檔。
Terris 後續提供了**授權的標章原檔**，本輪全部換掉。

### 我自己畫的那批已全數作廢

過程中曾嘗試手繪 SVG 徽章（圓弧印章、蛇杖、楓葉），**結果不可用，已放棄**。
記錄原因供日後參考：

- 用手寫路徑座標去湊**有機形狀**（蛇杖羽翼、楓葉輪廓）品質有天花板，改幾版都不像
- 後來改用現成幾何才解決：楓葉取自加拿大國旗 SVG 的官方路徑（公共領域）、蛇杖取自 game-icons.net
- 但既然有授權原檔，**原檔永遠優先**——驗證機構核發的標章才是合規用法

> **教訓：這類品牌／標章素材不要自己畫。** 先問有沒有原檔，沒有再談授權採購。

### 最終七枚（全部來自 Terris 提供的授權檔）

| 標章 | 處理 |
|---|---|
| ISO 27001 | 原檔是裸的 ISO 標誌，**依指示把號碼寫進藍色方塊**（下方加同色帶） |
| ISO 27701 | 同上 |
| ISO 13485 | 同上 |
| HIPAA Compliant | 去背、裁掉白邊 |
| PDPA Compliance | 去背 |
| PIPEDA | 去背，**裁掉底部那行小字**（認證列尺寸完全糊掉） |
| Bluetooth | 去背（黑色版） |

### 影像處理做法

1. **去背**：從四邊 flood fill，**不是**全域把白色變透明。
   全域替換會把 PDPA 中間那圈白底、ISO 的白色鏤空字一起吃掉，圖會破。
2. **單色化**：依 Terris 指示平塗為 **`#49515E`**（比照站上客戶 logo 牆的 treatment），
   **不是** CSS `filter: grayscale()`。判斷依據是 `min(r,g,b)`：
   近中性白（>225）保留白色，其餘轉 `#49515E`，170–225 之間做柔和過渡以保留反鋸齒。
   這樣 ISO 的白字、PDPA 的白色內圈都留得住。
3. **尺寸**：原檔 2000px 級縮到高度 360px（display 64px 的 2.6 倍，retina 綽綽有餘），檔案 9–66KB。

### Webflow Assets（共 14 個）

每個標章都上傳了**原色**與**單色**兩版，檔名前綴 `cert-` 與 `cert-mono-`。
認證列用單色版；原色版留著給文件、簡報或深色底情境。

### Hero 認證列實作

| Class | Desktop | ≤767px | ≤479px | 用於 |
