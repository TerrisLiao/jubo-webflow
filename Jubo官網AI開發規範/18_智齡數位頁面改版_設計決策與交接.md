## 6. ⚠️ 驗證限制（依 `CLAUDE.md` 必須標示）

1. **沒有視覺驗證。** 頁面是 Draft、未 Publish，本次全程透過 MCP 讀寫，**沒有截圖、沒有取得 computed style、沒有實機看過四個斷點的實際渲染**。所有 RWD 判斷是依 class 定義推導，不是量測結果。請在 Designer 預覽逐一確認後再決定是否發布。
2. **`_2col-grid` 的手機行為是推論。** 讀回四個斷點只有 base 與 main（`1fr 1fr`），沒有任何 medium/small/tiny 覆寫，據此判斷它在手機不會堆疊，所以加了 `is-stack-mobile` combo。若實際上有其他機制（例如 Slater CSS）已經在處理堆疊，這個 combo 就是多餘的，可以拿掉——但**不要改 `_2col-grid` 本體**。
3. **Navbar 的錨點連結沒有處理。** `Jubo-Digital-Navbar` 的連結目標寫在 **Component Definition 內部**，指向線上原頁的 section element id，在這一頁不會正確跳轉。修它就要動共用 Component（違反鐵律 5），所以停在這裡等你決定。頁尾三個連結已改成 hash 錨點、可正常運作。
4. **頁尾殘留 Relume 佔位文案未動。** `Jubo-Digital-Footer` instance 上仍有 `Text 5 = "Link Five"`、`Text 6 = "© 2025 Relume. All rights reserved."`、`Privacy Policy` / `Terms of Service` / `Cookies Settings`，且對應 Link 都是 `#`。實測線上頁**沒有渲染出這幾個字**（元素應為隱藏），所以判定為 inert、未修改。若之後要顯示版權列，要先確認正確的法人名稱再填。
5. **三個專案的 modal 長文沒有搬過來。** 原本 `section_popup` 裡有數位學習平臺、健康存摺 SDK、數位照護獎勵計畫三份深度說明，靠 IX2 互動開啟。MCP 無法建立 IX2，所以新頁改成：最強的一案（數位學習平臺）以旗艦區塊直接攤在頁面上（對 SEO／AEO 也比 modal 好），另外兩案的長文**目前不在新頁上**。原文仍完整保存在線上 `/ecosystem/jubo-digital`，沒有遺失。要救回來的話建議做成獨立案例頁，而不是再包 modal。
