## ⚠️ Glass Button 的內部結構不可自行仿製

`Glass Button`（102 個實例）的玻璃質感**不是單層半透明背景**，是 9 個 class 疊出來的：

```
glass-element
glass-effect
glass-effect__fill
glass-effect__fill-burn
glass-effect__highlight-soft
glass-effect__highlight-strong
glass-effect__edge-light
glass-effect__edge-dark
glass-effect__inner-glow
```

- **一律使用現有的 `Glass Button` Component**，不要用 `rgba()` 背景 ＋ `backdrop-filter` 自己刻一個「很像」的
- 這 9 個 class 的雙底線寫法是既有狀態，且 `.glass-button` / `.glass-text_wrapper` 被 Slater CSS 引用中
  （見 [`../custom-code/slater-selectors.md`](../custom-code/slater-selectors.md)）—— **不可改名**
- 不要在站上再加第三套按鈕樣式

## 卡片與按鈕的實際數值

> 來源：Webflow 站上 Agent Instruction `rules/jubo-web-visual-system.md` §9–§10（快照 2026-07-22）。
> **尚未逐項以 Designer 讀回驗證**，當參考值用；要精確數字請即時讀回並帶四個斷點。

### 一般正式卡片

白色／半透明白底、`1px` 淺色 border、`1.5–2rem` radius、低對比 shadow、`1.5–2rem` padding。

`single-stats_wrapper`：

| 斷點 | 高度 | Padding | Radius |
|---|---|---|---|
| Desktop | 24rem | 2rem | 2rem |
| Tablet | 20rem | 1.5rem | 1.25rem |
| Mobile | — | — | 約 1rem |

### 大型 Glass Card 參考值

| 屬性 | 值 |
|---|---|
| Border | `rgba(255,255,255,.78)` |
| Radius | `1.75rem` |
| Shadow | `0 18px 50px rgba(34,57,60,.075), inset 0 1px 0 rgba(255,255,255,.78)` |
| Backdrop blur | `22px` |

> **不要讓整頁每一段都變成卡片或玻璃。** 文字可以直接排版時，不要硬裝進卡片。

### CTA Button

| 屬性 | 值 |
|---|---|
| Radius | `1000px`（pill） |
| Padding（Desktop） | `.7rem 1.75rem .75rem` |
| Padding（Tablet） | `.5rem 1.5rem` |
| 配色 | 白字 ＋ `--primary--accent` 背景 |
| 必須保留的屬性 | `data-button-animate`、`data-button-animate-chars` |

CTA 文案用「動作＋結果」，不要只寫「了解更多」。

## 使用原則

1. **先查這份清單**再決定要不要新建元素
2. 要做變體 → 用 Component 的 Props / Variants，或在 instance 外層加 `is-` combo class
3. **不要**為了單頁需求去改 Component Definition — 會影響所有實例
4. **不要** unlink Component instance 後亂改；真的需要不同結構就開新的 Component
5. 新建 Component 時命名沿用既有風格（Title Case，例如 `Amy Lens Hero`）
6. 用 MCP 插入 instance 時**以 Component ID 為準**；實例數只是快照，不要拿來做判斷依據
