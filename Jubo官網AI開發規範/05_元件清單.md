## 使用原則

1. **先查這份清單**再決定要不要新建元素
2. 要做變體 → 用 Component 的 Props / Variants，或在 instance 外層加 `is-` combo class
3. **不要**為了單頁需求去改 Component Definition — 會影響所有實例
4. **不要** unlink Component instance 後亂改；真的需要不同結構就開新的 Component
5. 新建 Component 時命名沿用既有風格（Title Case，例如 `Amy Lens Hero`）
