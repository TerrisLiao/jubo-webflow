## 1. 這個網站是什麼

Jubo 官網是一個 **標準的 Finsweet Client-First v2 專案**（廠商建置）。稽核結果確認：

- 完整的 CF 核心結構（`page-wrapper` / `main-wrapper` / `section_*` / `padding-global` / `container-*` / `padding-section-*`）都在
- 130 個 CF 官方 utility class 完整存在
- 有 `/style-guide` 頁面（Draft），內含 `fs-styleguide_*` 官方樣板
- 有 `Global Style` component（35 個實例）＝ CF 的 global-styles embed

**這代表：任何新頁面、新區塊都必須沿用這套系統，不能另起爐灶。**

## 2. 五條鐵律（違反就是錯的）

### 鐵律 1：先找、再用、最後才建

建立任何元素前的順序：

1. 查 `03_全域工具類清單.md` → 有沒有現成 utility class 可用？
2. 查 `05_元件清單.md` → 有沒有現成 Component 可直接插入？
3. 查 `06_自訂Class完整清單.md` → 有沒有同性質的 `folder_element` class 可沿用？
4. 都沒有 → 才新建，且必須符合鐵律 2 的命名法。

**禁止**為了「比較快」而新建一個功能等同既有 class 的新 class。

### 鐵律 2：命名法只有兩種，沒有第三種

| 類型 | 語法 | 範例 | 說明 |
|---|---|---|---|
| Utility class | 只用連字號 `-`，**不可有底線** | `text-size-large`、`margin-bottom`、`padding-large` | 全站共用，改一個影響全站 |
| Custom class | `folder_element`，**必須有底線** | `product-features_card`、`hero-solutions_image` | 一個底線 = 一層 folder |
| Combo class | 基底 class ＋ `is-` 前綴 | `.cta-button.is-filter`、`.section_hero.is-home` | 變體一律 `is-` 開頭 |

**絕對禁止的命名**（本站已有前例，不要再增加）：

- ❌ 扁平連字號自訂 class：`jp8-journey-card`、`jbc-v3-tab`、`jp3-method-image`
  → 正確應為 `jp-journey_card`、`jbc_tab`、`jp-method_image`
- ❌ 雙底線 BEM 寫法：`tab-layout__col__wrap`、`cards-stack__item`、`tab-visual__item`
  → CF 的雙底線代表兩層 folder，不是 BEM 修飾符
- ❌ class 名稱含 `#`：`section_product-hero#3`、`single-icon#1`
- ❌ Webflow 預設名稱：`Heading`、`Paragraph`、`Image`、`Link`、`Div Block 12`
- ❌ 變體不加 `is-`：`.jp7-layer-card.jp7-layer-one`、`.tab-visual__item.active`、`.footer-icon._1`
- ❌ 底線寫成 `is_`：`.app-wrap.is_align-right`、`.icon-embed-logo.is_home`
- ❌ 縮寫、無意義名稱：`col-2-d`、`btn`、`mm`、`helper`

### 鐵律 3：核心結構的巢狀順序不可改

```html
<div class="page-wrapper">
  <main class="main-wrapper">
    <section class="section_[識別名]">
      <div class="padding-global padding-section-[size]">   <!-- 兩個 class 疊同一層 div -->
        <div class="container-[size]">
          <!-- 內容 -->
        </div>
      </div>
    </section>
  </main>
</div>
```

- `padding-global` 只管左右 padding，**不要加任何其他 CSS**
- `padding-section-*` 只管上下 padding，**必須跟 `padding-global` 疊在同一個 div**，不要多包一層
- `container-*` 只管 `max-width` + `margin: auto` + `width: 100%`
- `section_*` 盡量不上樣式，需要背景色就疊 `background-color-*`

### 鐵律 4：不要寫自訂 CSS、不要用 HTML Embed 做版面

- 顏色一律用 Variables（見 `04_設計變數與色彩.md`），不要手打色碼
- 間距一律用 `margin-*` / `padding-*` / `spacer-*` utility 或 Variables，不要手打 px
- 尺寸一律用 `rem`（1rem = 16px），只有 border 用 px
- **禁止**用 HTML Embed / Code Block 畫版面、畫假 UI、畫卡片
- 需要的效果如果站上真的沒有，先問 Terris，不要自己造一套「很像 Jubo」的樣式

### 鐵律 5：不要動共用資產

以下屬於全站共用，**未經明確指示不得修改**：

- 所有 Component Definition（Navbar、Footer、CTA Button、Announce Bar、Section Tag、Global Style、Cookies…）
- 所有 utility class 的 CSS 值（改一個會影響全站 30+ 頁）
- Variables 的值
- `body` / `h1`~`h6` / `p` / `a` 等 tag selector

要做單頁變體 → 用 `is-` combo class 或新的 `folder_element` custom class。

## 3. Class 疊加上限

| 一個元素上的 class 數 | 判定 |
|---|---|
| 1–2 | ✅ 理想 |
| 3 | ⚠️ 可接受，但先想想能不能合併 |
| 4 | ⚠️ 極限 |
| 5＋ | ❌ 禁止，改用單一 custom class |

例外：CF 官方的兩段式間距寫法算正常，不算疊加問題 —
`margin-bottom margin-small`、`padding-vertical padding-large`、`padding-global padding-section-large`。

## 4. Landing Page / 獨立頁面的做法

若需要**沒有 Navbar / Footer 的獨立 Landing Page**：

1. 從既有頁面複製時，把 `Navbar`、`Footer`、`Announce Bar` 這三個 component instance **刪除**
2. **保留**：`Global Style`、`Cookies`、`page-wrapper`、`main-wrapper`、`Page Gradient BG`
3. section 一律用 `section_[新識別名]`，沿用 `padding-global padding-section-*` + `container-*`
4. 頁面專屬樣式 → 新開一個 folder，例如 `amy-lens_hero-visual`（**不是** `amy-hero-visual`）
5. 完成後檢查：頁面內 `Navbar` = 0、`Footer` = 0、HTML Embed = 0、自訂 CSS = 0

## 5. 收工前的自我檢查清單

每次改完，逐項確認：

- [ ] 新增的 class 有沒有底線？是 utility 就不該有，是 custom 就一定要有
- [ ] 所有變體 class 都是 `is-` 開頭？
- [ ] 有沒有元素疊了 5 個以上 class？
- [ ] 核心結構順序對嗎？`padding-global` 跟 `padding-section-*` 疊同層了嗎？
- [ ] 有沒有手打色碼？（應該用 Variables）
- [ ] 有沒有手打 px？（border 以外應該用 rem）
- [ ] 有沒有新增 HTML Embed / Code Block？
- [ ] 有沒有動到 Component Definition 或既有 utility 的 CSS？
- [ ] Heading 標籤層級是否連續（H1→H2→H3，不跳級）？
- [ ] 頁面是否維持 Draft、未 Publish（除非明確要求發布）？
- [ ] 有沒有在 Style Manager 留下沒用到的孤兒 class？（有就刪掉）

## 6. 已知的地雷（本站實況，務必避開）

### 6-1. 三個顏色 utility 的值是「範本殘留」，不是 Jubo 品牌色

| Class | 實際值 | 問題 |
|---|---|---|
| `text-color-brand` | `hsl(81, 98%, 61%)` 螢光黃綠 | 不是 Jubo 色，是 CF 範本預設 |
| `text-color-brand-dark` | `#36852f` 綠 | 同上 |
| `background-color-secondary` | `hsl(81, 98%, 61%)` 螢光黃綠 | 同上 |
| `background-color-tertiary` | `#6e30f7` 紫 | 同上 |

**不要使用這四個 class。** Jubo 主色是 `--primary--accent` `#00b2c0`（teal）。

### 6-2. 有兩套重複的結構 class

- `page-wrapper` ✅ 正確　vs　`page-wrap` ❌ 後來加的重複品
- `main-wrapper` ✅ 正確　vs　`main-wrap` ❌ 後來加的重複品

一律用 `-wrapper` 版本。

### 6-3. `hide-mobile` 不是 CF 標準

CF 標準只有 `hide`、`hide-tablet`、`hide-mobile-landscape`、`hide-mobile-portrait`。
站上的 `hide-mobile` 是後來加的，新工作請用標準四個。

### 6-4. 錯字 class

`css-tootlip__tip`（正確拼法是 `css-tooltip`）— 與正確的 `css-tooltip__*` 系列並存，不要沿用錯字版本。

### 6-5. 兩套非標準的 section padding

站上額外有 `padding-section-xlarge`（11rem）與 `padding-section-full`（95vh flex 置中）。
這兩個是專案擴充，可以用，但要知道它們不是 CF 原生。
另外 CF 標準的 `padding-section-medium` **本站沒有**，不要引用。

### 6-6. ⚠️ 有一批 class 被 Slater 外部程式碼鎖住，**不可改名**

站台 head/footer 載入了兩個 **Slater 託管**的外部檔案（不在 Webflow 裡，MCP 也讀不到）：

- `https://slater.app/20018/60294.css` — 全站互動樣式、`@font-face JuboFont`
- `https://slater.app/20018/60292.js` — GSAP／Swiper 互動

它們用 **class 選擇器**直接抓 Webflow 元素。**改掉這些 class 的名字，線上會壞版或壞互動，而且 Webflow 內不會有任何錯誤提示。**

完整清單見 [`custom-code/slater-selectors.md`](../custom-code/slater-selectors.md)。動手改名前**一定要先查那份文件**。

最常踩到的幾個：
`.cascading-slider__*`（雙底線）、`.cascading-slider_content-wrap` / `_content-wrapper`、`.cta-button`、`.cta-button_bg`、`.glass-button`、`.gradient-icon.is-1/.is-2`、`.icon-embed-medium`、`.card-wrapper`、`.richtext`、`.tab-visual__item`、`.tab-content__*`、`.slider-cms-*`、`.category-tag`

> 這解釋了為什麼 `07_合規稽核報告.md` 裡那批雙底線 BEM **不能**照 Client-First 正名 —
> 不是沒人想修，是它們被外部程式碼綁死了。遇到這種情況，**在文件註記原因，不要硬改**。
>
> 另外，`.category-tag` 被站台 head 的 GA4 程式碼用來推斷業務區域，改名會讓分析靜默失效。
>
> **Slater 屬於整個網站的背景設施，不在一般改版的修改範圍內。**
