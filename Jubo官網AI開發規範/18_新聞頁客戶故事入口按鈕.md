# 18｜`/news` 新聞中心 — 新增「客戶成功故事」玻璃入口卡

- 日期：2026-10-01
- 站台：`jubo-health.com`（site id `69ec2b02daa2e79f1da8772a`）
- 頁面：`新聞中心`（page id `6a029c4af6ffcfde1b409c31`，slug `news`，**已上線頁面**）
- 委託：Terris（轉達主管會議決議）— 「客戶故事目前只能從首頁滑到最底才找得到；新聞已在 header，要在新聞頁加一個可以前往客戶故事的入口，要跟一般篩選按鈕不一樣」
- 狀態：**已在 Designer 修改，未 Publish**（需 Terris 明確授權才發布）

---

## 1. 結果

篩選按鈕列**上方**多一張置中的玻璃 pill 卡片，連到 `/customer-success-stories`（page id `6a1cd470a75f99c148ea2cfe`）：

```
[ 客戶成功故事 ]  看看長照機構的真實導入故事  (→)
  漸層小標籤        深色說明文字                白底圓形箭頭
```

設計上刻意跟篩選按鈕做出三個差異，讓使用者一眼分辨「這是去另一頁」而不是「篩選這頁」：

| | 篩選按鈕（既有） | 客戶故事入口（新增） |
|---|---|---|
| 位置 | 同一列，橫排 | 獨立一行，在篩選列上方置中 |
| 外觀 | teal 實心 pill | 半透明白色玻璃底＋白邊框＋極淡 teal→紫 漸層，內含漸層小標籤 |
| 導覽暗示 | 無 | 右側圓形 `→` 箭頭；hover 時整張卡片上浮、陰影加深 |

玻璃質感沿用客戶故事區塊的設計語言（`hero-customer-story_wrapper`：`neutral/white-30` 底＋白色 1px 邊框；`customer-story_content-wrap` 的柔和陰影），漸層小標籤用全站品牌漸層（`--primary--accent` → `--gradient--announce-bar-purple`，同 `.gradient-headline`）。

```html
<div class="news-grid_component">                                       <!-- 既有，flex column -->
  <a class="news-story-link_component" href="/customer-success-stories"> <!-- 新增 -->
    <div class="news-story-link_tag">客戶成功故事</div>
    <div class="news-story-link_text">看看長照機構的真實導入故事</div>
    <div class="news-story-link_icon" aria-hidden="true">→</div>
  </a>
  <div class="news-filter_form-block">…篩選表單，完全未修改…</div>          <!-- 既有 -->
  <div class="news-content_list-wrap">…文章列表…</div>                      <!-- 既有 -->
</div>
```

- 卡片放在**篩選表單外面**。Slater JS（`initNewsFilterDropdown()`）只處理 `.news-filter_form` 內部的元素，所以卡片不會被當成篩選選項，也不會被手機版下拉選單的邏輯藏起來或移位。
- 沒有用 `cta-button`：它是 teal 實心按鈕，視覺上會跟篩選按鈕太像；也沒有用 `Glass Button` component（`05` 規定其內部 9 個 class 不可自行仿製，且它的結構是單一文字按鈕，放不下「標籤＋說明＋箭頭」）。

## 4. 歷程：第一版為什麼失敗

第一版（同日）把按鈕做成 `a.cta-button.is-customer-story`，**放在 `news-filter_form` 篩選列裡面**、排在類別按鈕最後。
Terris 回報截圖：**篩選按鈕全部被擠到文字換行、嚴重變形**（「所有文 / 章」這種斷行）。

原因：`news-filter_form` 是不換行的 flex row，原本的篩選按鈕剛好放得下；多塞一顆按鈕後總寬超出 container，
其他按鈕被 flex 壓縮，而篩選按鈕的文字沒有 `nowrap`，就被擠成兩行。

另外 Terris 指出設計方向也不對：篩選按鈕是「篩選這頁」，客戶故事是「前往另一頁」，兩者應該在視覺上明確區分、而且入口要放在所有按鈕上方。

已處理：刪除第一版元素與 `cta-button > is-customer-story` combo（Style Manager 無殘留），改為本文件的第二版。

**教訓：不要往既有的 flex row 裡塞東西，除非先確認它在最寬的內容下還放得下。**
另外，Slater 會對 `.news-filter_form` 內每個 `.cta-button.is-filter` 切換 `is-active`，手機版還會藏掉 form 直屬的 `.cta-button.is-filter`；
這也是另一個不該把非篩選元素放進這個 form 的理由（見 `custom-code/slater-selectors.md`）。
