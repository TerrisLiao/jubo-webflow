## 1. 結果

新聞頁篩選列多一顆按鈕「客戶成功故事 →」，連到 `/customer-success-stories`（page id `6a1cd470a75f99c148ea2cfe`）。

| 斷點 | 位置與外觀 |
|---|---|
| Desktop | 篩選按鈕列最右側（在 CMS 類別按鈕之後），多 `0.5rem` 間隔；teal → 紫色漸層 pill、白字、紫色柔光陰影 |
| Hover | 漸層往右滑（`background-position` 0% → 100%）、陰影加深；文字沿用全站 CTA 的逐字上滾動畫 |
| Tablet / Mobile（≤991px） | 篩選列在這個尺寸會收成下拉選單，所以按鈕用 `order: -1` 移到下拉觸發器**上方**、置中，與觸發器間隔 `0.5rem` |

## 2. 結構

```html
<form class="news-filter_form" fs-list-element="filters">
  <label class="cta-button is-filter is-active">所有文章</label>        <!-- 既有 -->
  <label class="category-radio_field is-mobile">…</label>              <!-- 既有，手機下拉觸發器 -->
  <div class="news-category_list-wrap">…CMS 類別…</div>                 <!-- 既有 -->
  <a class="cta-button is-customer-story" data-button-animate
     href="/customer-success-stories">                                  <!-- 新增 -->
    <div class="btn-animate-chars__text" data-button-animate-chars>客戶成功故事 →</div>
  </a>
</form>
```

- 標記方式比照 `CTA Button` component 的根元素（`a.cta-button[data-button-animate]` ＋ `[data-button-animate-chars]` 文字層），所以 Slater 的逐字 hover 動畫會自動套用。
- **沒有**改用 `CTA Button` component instance：要上漸層必須在根元素加 combo，等於改 Component Definition（鐵律 5）。
- 內部文字層是 Div（`btn-animate-chars__text`，沿用既有 class），CTA Button component 用的是 `span`；Slater CSS 會把 `[data-button-animate-chars]` 設成 `inline-block`，渲染結果相同。

---

## 3. 為什麼一定**不能**用 `.is-filter`

Slater JS（`slater.app/20018/60292.js`，`initNewsFilterDropdown()`）會對 form 內**每一個** `.cta-button.is-filter` 切換 `is-active`，
Slater CSS 也會在 ≤991px 把 `.news-filter_form > .cta-button.is-filter` 直接 `display:none !important`。

如果新按鈕掛 `is-filter`：

1. 點其他類別時它會被加上／拿掉 `is-active`，被當成一個篩選選項。
2. 手機版會被整顆藏掉。

所以新按鈕掛的是 `cta-button` ＋ 新的 `is-customer-story` combo，**完全不碰 `is-filter`**。
它也沒有 `fs-list-field` / `fs-list-value`，Finsweet List Filter 不會把它當成篩選欄位。

## 4. 新增的 class

只新增一個 combo：**`.cta-button.is-customer-story`**（style id `2a3527cb-71f0-9bdd-2144-fd132801fc4d`）。
沒有修改 `cta-button`、`is-filter`、`news-filter_form` 或任何共用 class 的值。

| 狀態 | 屬性 |
|---|---|
| base | `flex-grow: 0`、`margin-left: 0.5rem`、`line-height: 150%`（與 `is-filter` 同高）<br>`border: 1px solid var(--neutral--white-30)`<br>`background-image: linear-gradient(90deg, var(--primary--accent), var(--gradient--announce-bar-purple), var(--primary--accent))`<br>`background-size: 200% 100%`、`background-position: 0% 50%`<br>`box-shadow: 0 0.5rem 1.25rem -0.5rem var(--gradient--purple)`<br>`color: var(--neutral--white)`<br>`transition: background-position, box-shadow 0.6s cubic-bezier(0.625, 0.05, 0, 1)` |
| hover | `background-position: 100% 50%`、`box-shadow: 0 0.75rem 1.75rem -0.5rem var(--gradient--purple)` |
| medium（≤991px） | `order: -1`、`align-self: center`、`margin-left: 0rem`、`margin-bottom: 0.5rem` |

- 漸層用的是全站既有的品牌漸層（teal `--primary--accent` → 紫 `--gradient--announce-bar-purple`），與 `.gradient-headline`、Announce Bar 同一組顏色，沒有新增顏色或變數。
- 漸層頭尾都是 teal，`background-size: 200%` 讓 hover 時可以平滑滑動，不會跳色。
- 若漸層沒有生效，底下仍有 `cta-button` 本身的 teal 底色，不會變成透明按鈕。

## 5. 驗證限制（未完成項目）

- ⚠️ **沒有拿到視覺快照**：本次 Designer 的 MCP app 沒有連線，`element_snapshot_tool` 無法執行。
